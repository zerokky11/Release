KKY Tool Revit 기능 정리

이 문서는 KKY Tool Revit의 주요 기능을 사용자 관점에서 정리하기 위한 매뉴얼 초안입니다. 현재 매뉴얼 인덱스에서는 메뉴 구조와 기능별 역할, 검토 요소, 수행 요소, 결과물을 중심으로 먼저 정리하고 있습니다.

납품 시 BQC 검토

BQC Main

납품 시 BQC 검토

HighTech 현장에서 납품 시 주요 항목을 검토하는 기능으로 구성되어 있는 메인 허브 그룹 중 하나입니다.

역할

납품 시 정해진 검토 프로세스에 검토 정밀성 및 시간 절약에 도움을 주는 역할을 합니다.

검토 요소

중복 모델링이나 자체 간섭, 속성 누락, 속성 입력값 검토 및 납품 파일 정리 등

Workflow

RVT 정리 (납품용)

뷰 정리, 필터 적용, 파라미터 입력, 검토, 속성 추출, Purge까지 납품용 파일을 만들기 위한 정리 과정을 한 흐름으로 묶은 기능입니다.

역할

납품용 RVT 산출물을 만들어내는 정리 워크플로우.

검토 요소

3D 뷰 상태, 링크/그룹/조립/Design Option, 필터 적용 상태, 추출 대상 속성.

결과물

정리된 RVT, 검토 엑셀, 로그, Purge 결과표.

주의: RVT 직접 수정형 기능입니다. 작동 방식과 옵션 설정에 대한 설명을 상세 메뉴얼에서 필수로 확인하세요.

BQC Core

파라미터 연속성 검토

상세 매뉴얼

연결된 객체끼리 지정 파라미터 값이 연속적으로 이어지는지, 허용 오차 내에서 연결 상태가 정상인지 검토합니다.

역할

MEP 모델 요소의 파라미터 연속성 검토.

검토 요소

배관, 덕트, 전기 연결 계통의 객체 간 지정 파라미터 값의 불일치, 누락, 잘못된 연속성 검토.

결과물

객체 연결 여부, 불일치 목록, 추가 검토 파라미터 포함 결과 엑셀.

BQC Sub

레벨 영역별 파라미터 검토

상세 매뉴얼

레벨의 절대 Z 좌표를 경계로 사용해 요소 위치를 판정하고, 층정보 파라미터 값이 기대값과 맞는지 확인합니다.

역할

층 영역으로 구분되는 파라미터 값의 일치여부 검토.

검토 요소

층정보 값 누락, 잘못된 층 표기, 경계층 인접 요소.

결과물

지정한 파라미터에 입력된 기대값과 실제로 입력된 값의 불일치 오류 목록.

Review + Action

중복 / 자체간섭 검토

중복 MEP 요소 그룹과 자체간섭 후보를 한 화면에서 확인하고, 선택, 삭제, 복원, 엑셀 내보내기까지 수행 합니다.

역할

중복요소와 자체간섭을 탐지하여 중복 물량산출 방지 및 모델링 오류를 잡아냅니다.

검토 요소

같은 위치의 중복 요소, 겹침/통과 등의 간섭 요소 검토 (SET 설정으로 검토 대상 필터링 가능)

결과물

중복 요소 및 간섭 요소를 그룹 및 쌍으로 정리하여 엑셀 출력. (중복의 경우 창에서 직접 확인 및 삭제/되돌리기 가능)

주의: 삭제/복원은 실제 모델 변경입니다. 검토자가 직접 수행하기보다 검토 결과를 추출하여 작업자에게 전달하는 편을 권장 합니다.

유틸리티

Utility Main

유틸리티

평소 패밀리 관리, 파라미터 추가, 센트럴 파일의 건전성 관리에 도움을 주는 기능으로 구성되어 있는 메인 허브 그룹 중 하나입니다.

역할

평소 센트럴 파일 건전성 (파라미터 GUID 일치여부, 복합 패밀리 파라미터 연동 등)을 검토하는데 도움을 주는 역할을 합니다.

검토 요소

프로젝트 상에 추가되어있는 파라미터/공유파라미터, 패밀리 파라미터 검토, Segment와 PMS 간 OD, ID 일치여부 검토 등 프로젝트를 구성하는 Setting 에 대한 검토.

Utility

복합패밀리 공유 파라미터 추가/연동

복합 패밀리의 하위 패밀리에 공유 파라미터를 추가 및 연동 까지 수행하고, 호스트와 연동 상태를 점검하는 기능입니다.

역할

패밀리 표준화와 하위 패밀리 파라미터 건전성 유지 및 연동 확인.

검토 요소

동일 파라미터 추가 및 연동 수행 후, 파라미터 추가 누락 및 GUID 일치여부. 잘못된 연동 검토.

결과물

추가/연동 수량, 연동 대상과 연동 여부 확인 후 엑셀로 결과 추출.

Batch Add

Project Parameter 추가 (Project/Shared)

프로젝트 또는 공유 파라미터를 여러 RVT에 한 번에 추가하는 도구입니다.

역할

여러 프로젝트 파일에 동시에 추가해야하는 파라미터 존재 시 같은 카테고리, 설정으로 한번에 추가 하는 기능.

수행 요소

Shared Parameter, 바인딩 카테고리(Sub Category 포함), 인스턴스/타입 여부 선택 후 해당 설정으로 파라미터 추가.

결과물

실행 로그, 성공/실패 결과 엑셀 추출.

Modify

파라미터 수정기

필터 조건에 맞는 요소만 골라 파라미터 값을 일괄 수정하는 기능입니다.

역할

필터에 해당하는 모든 모델 객체에 대해 지정한 파라미터에 입력값을 일괄 적용합니다.

수행 요소

한번에 여러 RVT 파일을 선택하여 적용, 저장 및 Central File 의 경우 동기화 (입력한 내용으로 Comment 작성 가능)

결과물

필터 조건에 맞는 객체 수, 실제 매칭 수, 수정된 객체 수 집계. 로그파일 엑셀 추출.

Utility

PMS 검토

Revit의 Segment, Routing Preference, Pipe Size와 PMS 기준표를 비교해 매핑과 사이즈 일치 여부를 검토합니다.

역할

초기 설정과 실제 배관 타입의 규격 검토.

검토 요소

재질 기반으로 Segment 후보, PMS 클래스 매핑, ND/ID/OD 비교

결과물

매핑표, Revit 사이즈표, PMS 사이즈 비교 및 오류 대상 엑셀 추출.

Utility

파라미터 GUID 검토

Shared Parameter로 추가된 프로젝트 파라미터 및 패밀리 파라미터의 GUID가 현재 Shared Parameter text 파일과 일치하는지 확인합니다.

역할

프로젝트 및 패밀리 파일의 파라미터 건전성 검토.

검토 요소

프로젝트/패밀리 내 GUID 불일치, GUID가 다른 중복 파라미터 검토. 파라미터 추가 여부

결과물

검토 결과에 따른 각종 오류 사항 엑셀 추출.

Utility

패밀리 공유파라미터 연동 검토

호스트 패밀리와 중첩 패밀리 간 공유 파라미터 연동 상태를 검토하고, 누락이나 GUID 불일치를 찾아냅니다.

역할

복합 패밀리의 파라미터 연동 검수. 공유파라미터일 경우 GUID 비교.

검토 요소

파라미터 연동누락, 상위 패밀리와 파라미터 GUID 일치 여부

결과물

연동 오류, GUID 일치여부 등의 이슈사항 엑셀 추출.

주의: 해당 기능은 복합 패밀리의 파라미터 연동 검토 기능입니다. 파라미터 추가 및 연동 수행기능은 복합패밀리 공유 파라미터 추가/연동 기능을 사용하세요.

Utility

프로젝트대상 Point 좌표 추출

Project Base Point, Survey Point, True North 값을 파일별로 추출합니다.

역할

프로젝트 파일 좌표계 검토.

검토 요소

Project/Survey Point 좌표, True North 각도, 파일별 좌표 편차.

결과물

검토 결과 엑셀추출.
