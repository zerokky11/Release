기본 흐름

대부분의 기능은 같은 순서로 실행합니다

기능마다 설정 내용은 달라도 대상 선택과 실행, 결과 확인의 위치는 같은 원칙을 사용합니다.

  1. 기능 선택

    BQC 검토 또는 일반 도구에서 필요한 기능을 선택합니다. 별도 화면 기능은 해당 기능의 전용 작업 화면으로 이동합니다.

  2. 기능 설정

    중앙 설정 영역에서 검토 기준, 파라미터, 허용값과 옵션을 입력합니다. 선택 실행형 기능은 공통 설정과 기능별 설정을 모두 확인합니다.

  3. 대상 선택

    현재 열린 모델은 활성 문서 실행을 사용합니다. 여러 파일을 처리할 때는 여러 RVT 실행을 눌러 별도 등록 창에서 RVT를 추가합니다.

  4. 실행

    필수 설정과 대상이 준비되면 오른쪽 실행 버튼이 활성화됩니다. 비활성 상태라면 같은 패널의 준비 조건을 먼저 확인합니다.

  5. 결과와 Excel

    결과창에서 정상·오류 건수와 상세 항목을 확인합니다. 여러 RVT 결과는 한글/영문과 한 파일/파일별 저장 방식을 조합해 내보낼 수 있습니다.
