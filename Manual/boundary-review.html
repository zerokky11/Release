파일 경계 연속성 검토

서로 다른 모델의 배관 등이 만나는 곳에서 끝점의 위치와 파라미터를 비교합니다. 맞은편 원본에 상대가 없는 경우는 같은 파일 안의 미연결 끝점과 구분해 확인할 수 있습니다.

설정하고 실행하기

  1. 원본 등록: 검사할 원본에 맞는 방식을 고릅니다. 여러 파일을 비교할 때는 파일 등록·관리를 열어 파일과 경로를 확인합니다. 같은 이름의 원본이 여럿이면 경로 또는 원본 구획까지 구분합니다.
  2. 비교 항목: 값의 연속성을 확인할 파라미터를 한 줄에 하나씩 적습니다. 원본마다 이름만 다른 같은 항목은 Line Number|LINE_NO처럼 |로 구분합니다.
  3. 후보 검색: 위치와 방향이 맞는 끝점을 찾을 거리와 각도를 지정합니다. 허용 범위를 크게 잡으면 가까운 다른 배관이 후보에 들어올 수 있으므로 프로젝트의 모델링 공차에 맞춥니다.
  4. 작업 경계 지정: 원본 A·B, 공유좌표의 X/Y/Z 기준면과 위치, A에서 B로 향하는 방향, 면 안의 두 좌표 구간을 지정합니다. 예를 들어 mm 단위에서 A와 B가 X=12000에서 만나면 X 기준면에 12000을 입력하고 실제 접합부의 Y·Z 범위를 지정합니다.
  5. 경계 관찰 거리: 상대가 없는 끝점이 작업 경계에 얼마나 가까울 때 확인 대상으로 볼지 정합니다. 두 끝점을 짝으로 찾는 후보 검색 거리와는 다른 값입니다. 경계가 확실하지 않다면 작업 경계 자동 추정을 사용할 수 있지만, 확실한 접점 쌍이 모이지 않은 구간은 직접 지정해 확인합니다.
  6. End Dummy에 연결된 끝점도 검토: RVT 검토의 경계와 판정 기준에서 선택합니다. 기본값은 꺼짐입니다. 켜면 기존 열린 끝점과 함께, 같은 분야의 End Dummy 피팅에 실제 연결된 배관·덕트·케이블 트레이 또는 각 피팅의 끝점도 비교합니다. 예를 들어 한쪽 배관 끝에 End Dummy가 연결돼 있어도 다른 파일의 맞은편 배관과 비교할 수 있습니다.

설정을 확인한 뒤 검토를 실행합니다. 등록한 작업공유 RVT는 선택한 원래 파일 경로에서 디태치하고 사용자 웍셋을 닫아 엽니다. 새로 연 검토용 호스트는 로드된 RVT 링크를 내리고 호스트 요소만 읽은 뒤 저장하지 않고 닫습니다. 이미 열린 사용자 문서는 상태를 바꾸지 않고 재사용합니다.

결과 읽기

후보가 있는 끝점

서로 다른 원본의 끝점 쌍과 비교한 파라미터 값을 확인합니다. 파라미터 값이 같더라도 위치나 방향 검토가 필요한 후보를 정상 접점으로 확정하지 않습니다.

경계 상대 없음

끝점이 지정된 경계에 가깝지만 검토한 맞은편 원본에서 상대를 찾지 못한 경우입니다. 상대 모델의 배관이 실제로 누락됐는지 확인합니다.

상대 파일 미검토

맞은편 파일이 등록되지 않았거나 판독이 완전하지 않은 경우입니다. 누락으로 단정하지 말고 원본과 검토 범위를 확인한 후 다시 실행합니다.

내부 단절 추정

경계 근처에 있어도 방향과 위치가 경계 상대를 가리키지 않는 끝점입니다. 같은 원본 안의 연결 상태를 우선 확인합니다.

End Dummy는 한 피팅의 패밀리 이름에 End와 Dummy가 모두 들어 있는지로 구분합니다. 이름의 대소문자와 단어 순서는 상관없습니다. 타입명에만 있거나 실제 연결 없이 맞닿은 더미는 이 옵션으로 추가하지 않습니다. 결과의 ID와 파라미터는 더미가 아닌 원래 요소의 값이고, 검토 설정 → End Dummy 접점에 실행 당시 선택이 표시됩니다.

결과의 검토 설정 탭에서 실행 당시 조건을 확인합니다. 파일 목록이나 경계를 바꿔 다시 검사해야 하면 설정으로 돌아가고, 결과 전체를 전달할 때는 전체 엑셀 저장 또는 전체 CSV 저장을 사용합니다.
