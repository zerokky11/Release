NWC Exporter plus

등록한 RVT의 3D 뷰를 NWC로 추출하고, 선택한 발행 방식에 따라 NWD로 통합합니다. KKY Tool 3.1.30부터 파일·예약 작업에 동시 처리 RVT 수를 지정할 수 있습니다.

등록과 실행동시 처리 설정처리 순서

이 페이지는 KKY Tool과 함께 설치되는 NWC Exporter plus 1.0.1의 파일·예약 화면을 설명합니다. KKY Hub 안의 이전 NWC Export 화면은 기존 화면 매뉴얼을 참고하세요. 두 화면의 설정과 실행 방식은 다릅니다.

RVT와 3D 뷰를 등록한 뒤 실행합니다

Revit 리본의 NWC Exporter plus를 열고 파일·예약 탭으로 이동합니다. 활성 문서 탭에는 이 병렬 파일 설정을 적용하지 않습니다.

  1. 작업 선택

    왼쪽에서 기존 발행 작업을 고르거나 새 작업을 누릅니다. 작업 이름과 Revit 버전을 정합니다. 한 작업에는 같은 Revit 버전으로 처리할 파일을 등록합니다.

  2. 발행 방식과 저장 위치

    모델·출력에서 NWC 파일만 게시할지, NWD로 통합할지 선택합니다. 결과 폴더는 실행 PC에서 접근하고 쓸 수 있는 위치여야 합니다. NWD 통합에는 화면에 표시되는 해당 연도의 Navisworks Manage/Simulate가 필요합니다.

  3. 파일과 뷰

    RVT 추가로 파일을 등록하고, 각 행의 3D 뷰 이름 · 직접 입력에 실제 뷰 이름을 입력합니다. 예를 들어 파일에 NWC_EXPORT라는 3D 뷰가 있다면 그 이름을 입력합니다. 같은 파일에서 다른 뷰도 추출하려면 뷰 추가를 사용합니다. 실행할 행의 사용 체크를 확인합니다.

  4. 추출 옵션

    NWC 추출 설정에서 동시 처리 RVT 수, 좌표와 링크 포함 여부 등 작업 공통 옵션을 정합니다. 서로 다른 옵션이 필요한 모델은 작업을 나누어 등록합니다.

  5. 저장과 실행

    변경 저장 후 사전 점검을 실행합니다. 경로·뷰 이름·지원 버전 등의 오류를 정리하고 지금 실행을 누릅니다. 사전 점검 성공은 실제 RVT 열기와 추출 성공을 보장하는 것은 아닙니다.

  6. 결과 확인

    실행 기록에서 뷰별 처리 결과와 오류를 확인하고 결과 폴더의 생성 파일을 확인합니다. 일부 파일이 만들어졌더라도 실패·취소·작업자 종료 오류가 있으면 전체 정상 완료로 보지 않습니다.

동시에 처리할 RVT 파일 수

파일·예약 → 작업 선택 → NWC 추출 설정 → 동시 처리 RVT 파일 수에서 설정합니다. 작업마다 따로 저장하며, 기존 작업이나 새 작업의 기본값은 1개 · 순차 처리입니다.

선택값달라지는 동작설정 예
1개등록된 파일을 순차 처리합니다. 기존 작업 흐름을 유지합니다.큰 모델을 열거나 다른 Revit 작업을 함께 하는 PC.
2개서로 다른 RVT를 최대 두 개의 Revit 작업자에서 동시에 처리합니다.건축·구조 RVT 각각 한 개에 여러 뷰를 등록한 작업.
3개 또는 4개서로 다른 RVT의 동시 처리 상한을 세 개 또는 네 개로 늘립니다. 추출할 파일 수가 적으면 필요한 수만 실행합니다.여러 파일을 처리할 때 메모리 여유와 네트워크 사용량을 확인한 뒤 선택.

이 값은 뷰 수가 아닌 서로 다른 RVT 파일 수입니다. 같은 RVT의 뷰 네 개를 등록하고 4개를 선택해도 해당 파일의 뷰를 네 개의 Revit으로 나누지 않습니다. 동시에 여러 Revit을 실행하므로 메모리·CPU·디스크 사용량이 늘어납니다. 파일 크기와 PC 환경에 따라 오히려 느려질 수 있어 1개 또는 2개부터 확인하는 것이 좋습니다.

예: 건축·구조 두 파일에 뷰를 두 개씩 등록한 경우

A.rvt / 전체, A.rvt / 설비구간, B.rvt / 전체, B.rvt / 구조구간을 등록하고 2개를 선택하면 A와 B를 별도 Revit에서 처리합니다. A의 두 뷰는 A 작업자에서 순서대로, B의 두 뷰는 B 작업자에서 순서대로 추출합니다. 완료 시점이 달라도 결과 목록은 등록 순서를 유지합니다.

뷰별 예약이나 작업 예약으로 실행할 때도 해당 작업에 저장한 동시 처리 수를 사용합니다. 같은 PC에서 별개의 발행 작업을 여러 개 실행하는 제한까지 해제하는 옵션은 아닙니다.

함께 확인할 설정

설정의미와 예
공유 좌표 사용선택하면 공유 좌표, 해제하면 내부 좌표로 추출합니다. 모델을 통합할 때는 관련 RVT의 좌표 체계와 출력 옵션을 일관되게 맞춥니다.
Revit 링크 모델 포함링크 형상을 함께 추출할지 정합니다. 제외할 때는 추출용 문서의 링크를 언로드하는 기존 절차를 유지합니다. 원본 RVT를 저장하거나 센트럴에 동기화하는 옵션이 아닙니다.
리로드 후 진행해당 행을 추출하기 전에 문서를 다시 열어야 하는 기존 설정입니다. 같은 파일을 묶어 처리하더라도 이 요청을 생략하지 않습니다.
NWC 파일명 설정모델·출력 화면에서 기존 파일명 규칙을 지정합니다. 병렬 처리를 켜도 새 이름 규칙으로 바꾸지 않습니다. 중복 파일명은 사전 점검 결과를 확인해 정리합니다.
발행 결과: NWD 통합 게시추출 작업과 작업자 정리를 기다린 뒤 통합 가능한 NWC를 Navisworks에 전달합니다. 파일 오류가 있으면 성공 파일의 존재와 전체 작업 상태를 함께 확인합니다.

파일별 실행과 오류 처리

  1. 실행 대상 행을 정하고 RVT 전체 경로를 정규화합니다. 같은 경로의 뷰는 하나의 파일 그룹으로 묶습니다.
  2. 동시 처리 수가 2 이상이면 각 파일 그룹에 별도 Revit 작업자를 할당합니다. 요청·결과·로그·NWC·임시 로컬과 TEMP/TMP를 그룹별로 나눕니다.
  3. 각 그룹에서는 뷰를 등록 순서대로 처리합니다. 같은 문서를 재사용할 수 있으면 재사용하고, 리로드 요청이 있으면 기존 재열기 절차를 수행합니다.
  4. 파일별 오류를 남기고 다른 파일의 처리를 이어갑니다. 단, 작업자의 종료를 확인하지 못하면 새 파일을 시작하지 않고 NWD 통합도 보류합니다.
  5. 취소하면 새 파일을 시작하지 않고 실행 중인 작업자의 정리를 기다립니다. 결과는 완료 순서가 아닌 원래 등록 순서로 합칩니다.
  6. NWC 처리가 끝난 뒤 선택한 발행 방식에 따라 파일을 게시하거나 NWD를 통합합니다. 생성 파일과 작업자 종료 상태를 함께 판정합니다.

병렬 추출은 원본 RVT 저장·동기화를 추가하지 않습니다. 추출용 임시 로컬의 저장은 원본 저장과 구분되며, 기존 링크 제외와 전체 호스트 워크셋 열기 절차를 유지합니다.

확인 범위와 사용 시 주의점

Revit 2019에서 두 RVT·네 뷰를 동시에 처리하고 생성된 네 NWC의 호스트 객체와 링크 제외 결과를 Navisworks 2025에서 확인했습니다. 설정 저장·동시 처리 상한·파일 묶음·취소·오류 처리는 별도 관리 코드 검사로 확인했습니다.

다른 Revit 연도, 3~4개 실제 동시 실행, Family Browser가 없는 환경의 실제 병렬 실행, 현장 대형·공유폴더·ACC 모델의 성능, 공유좌표 수치 비교와 병렬 결과의 실제 NWD 통합은 이 확인에 포함되지 않았습니다. 과거 Revit 2019 종료 오류가 모든 환경에서 해결됐다는 뜻도 아닙니다.

배포 전에 사용 환경의 작은 작업으로 출력 위치·내용·오류 기록을 확인하세요. 메모리 부족이나 종료 오류가 있으면 동시 처리 수를 1개로 낮추고 해당 실행 기록을 확인합니다.
