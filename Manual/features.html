기능별 상세 매뉴얼

각 기능 페이지에는 사용 목적, 설정 순서, 실행 흐름, 검토 논리, 결과 확인 방법, 엑셀 추출 파일명 규칙을 따로 정리했습니다.

여러 RVT 검토 결과의 엑셀 저장 옵션은 한글/영문과 한 파일/파일별 저장 조합으로 나뉩니다. 기능별 페이지에서 실제 기본 파일명과 파일별 저장명을 확인할 수 있습니다.
