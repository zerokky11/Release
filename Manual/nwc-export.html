NWC Export

활성 문서 또는 여러 RVT의 비템플릿 3D View를 선택하고, 문서별 Revit 링크 로드 상태와 Navisworks Export 옵션을 적용해 NWC 파일을 일괄 생성합니다.

처음부터 실행하기 옵션 차이 보기
입력활성 문서 / 여러 RVT
범위선택한 3D View
출력View별 .nwc
결과 기록NWC Export Result.xlsx
빠른 시작

세 단계만 순서대로 준비합니다

대상과 링크를 정한 뒤 3D View를 고르고, 마지막에 저장 폴더와 Export 옵션을 설정합니다. 오른쪽 Workflow의 준비 항목이 모두 완료되어야 추출 버튼이 활성화됩니다.

  1. 대상 선택

    활성 문서 또는 여러 RVT를 등록합니다.

  2. 링크 계획

    문서별 링크 포함 여부와 Reload 대상을 정합니다.

  3. 3D View 선택

    문서별 View를 검색하고 체크합니다.

  4. 저장 폴더

    NWC 파일을 만들 폴더를 선택합니다.

  5. Export 옵션

    좌표, 파라미터, 형상 세부 수준 등을 정합니다.

  6. 실행·검증

    파일 생성과 크기·갱신 상태를 확인합니다.

가장 단순한 권장 설정 처음 실행은 활성 문서, Coordination 3D 한 개, Shared 좌표, Faceting Factor 1, 기존 파일 덮어쓰기 끔으로 시험합니다.

대상 RVT와 링크 로드 계획을 정합니다

활성 문서는 현재 Revit의 호스트 프로젝트 문서를 사용합니다. 여러 RVT는 별도 등록 창에서 파일을 선택하거나 드롭하고, 확인을 눌렀을 때 링크와 3D View 목록을 조회합니다.

설정동작예시
활성 문서ActiveUIDocument.Document 기준의 현재 호스트 프로젝트를 바로 조회합니다. 패밀리 문서와 링크 문서는 대상에서 제외합니다.현재 작업 중인 Plant_A.rvt
여러 RVT등록 순서대로 RVT를 열어 링크·View 정보만 수집하고 닫습니다. 동일 경로는 한 번만 등록합니다.분야별 납품 모델 12개 일괄 조회
링크 모델 포함문서 단위로 Revit 링크를 NWC에 포함할지 결정합니다. 끄면 그 문서의 모든 링크를 Export 대상에서 제외합니다.MEP 단독 NWC에는 링크 제외
링크 체크체크한 링크는 Export 직전에 Reload하고, 체크하지 않은 Loaded 링크는 Unload합니다.ARCH만 포함하고 STRUCT·SITE 제외
현재 상태처음 조회했을 때의 Loaded / Unloaded 상태로 선택을 되돌립니다.수동 조정 전 상태 복구
전체 Reload / Unload현재 선택 문서의 모든 링크를 한 번에 포함 또는 제외합니다.간섭 검토용 전체 링크 포함
원래 링크 상태는 보존됩니다 Export를 위해 링크 상태를 잠시 바꾸더라도 작업 완료 후 원래 상태로 복원합니다. 복원 실패는 결과의 링크 오류 건수에 기록됩니다.

문서별 3D View를 선택합니다

템플릿이 아닌 3D View만 표시됩니다. 왼쪽 문서 목록에서 RVT를 바꾸고, 오른쪽에서 이름 검색·전체 선택·선택 해제를 수행합니다.

  1. 문서 선택

    여러 RVT인 경우 각 문서의 View 수와 현재 선택 수를 문서 목록에서 확인합니다.

  2. 이름 검색

    NWC, Coordination 같은 View 이름 일부로 현재 문서 목록을 좁힙니다. 검색은 다른 문서의 기존 선택을 지우지 않습니다.

  3. View 체크

    선택한 View마다 NWC 파일 하나를 생성합니다. Perspective View는 별도 표시되므로 의도한 화면인지 확인합니다.

  4. 전체 선택 사용

    모든 문서 전체 선택은 조회된 모든 비템플릿 3D View를 선택합니다. 대량 생성이 될 수 있으므로 오른쪽 선택 View 수를 확인합니다.

저장 규칙과 Navisworks 옵션을 설정합니다

화면의 영문 보조 이름은 Navisworks Options Editor의 항목과 대응합니다. 처음 사용자는 기본값에서 좌표와 파라미터 범위만 업무 기준에 맞춰 조정하는 것이 안전합니다.

작동 논리

문서와 View를 순서대로 처리하고 생성 파일을 검증합니다

여러 RVT를 동시에 열어두는 방식이 아니라 등록 순서대로 하나씩 처리합니다. 한 문서나 View가 실패해도 다음 대상은 계속 진행합니다.

  1. Exporter 확인

    현재 Revit에 Navisworks Exporter가 사용 가능한지 확인합니다. 없으면 실행 버튼이 준비되지 않습니다.

  2. 문서 열기

    활성 문서는 그대로 사용하고, 여러 RVT는 등록 순서대로 열어 처리합니다.

  3. 링크 상태 기록

    현재 링크 Loaded / Unloaded 상태를 저장한 뒤 선택 계획에 따라 Reload 또는 Unload합니다.

  4. View별 Export

    선택한 View ID를 찾아 파일명 규칙과 옵션을 적용해 NWC를 생성합니다.

  5. 파일 유효성 확인

    NWC가 실제로 존재하고, 크기가 0보다 크며, 실행 시작 뒤 갱신됐는지 확인합니다. 파일 크기가 연속 두 번 안정될 때 완료로 판단합니다.

  6. 링크 복원·문서 닫기

    링크를 원래 상태로 돌리고 배치 문서를 닫은 뒤 다음 RVT로 넘어갑니다.

Revit 2019의 Faceting Factor 값이 1이면 리본이나 Options Editor를 열지 않고 Revit API로 바로 추출합니다. 1이 아니면 Navisworks 설정 창에 값을 자동 반영하는 별도 흐름을 사용하므로 화면 전환이 발생할 수 있습니다.

실행 전 점검

대량 Export 전에 확인합니다

  • Navisworks Exporter가 현재 Revit 버전에 설치되어 있음
  • 통합 좌표가 필요하면 Coordinates를 Shared로 선택
  • 필요한 링크만 Reload 대상으로 체크
  • 선택 View 수가 예상 NWC 수와 같은지 확인
  • 저장 폴더의 쓰기 권한과 여유 공간 확인
  • 기존 파일 덮어쓰기 여부를 의도대로 선택
  • Faceting Factor를 높이기 전 샘플 한 개로 용량 확인
  • 오류가 있어도 다음 문서는 계속되므로 결과 Excel 확인
