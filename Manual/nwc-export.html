NWC Export

활성 문서 또는 여러 RVT의 비템플릿 3D View를 직접 고르거나 이름으로 일괄 지정하고, Revit 링크 처리와 Navisworks Export 옵션을 적용해 NWC 파일을 생성합니다.

빠른 시작

세 단계만 순서대로 준비합니다

여러 RVT는 View 목록을 미리 읽는 방식과 View 이름만 먼저 적는 빠른 방식 중 하나를 선택합니다. 그 다음 링크 처리, 3D View, 저장 폴더와 Export 옵션을 준비합니다. 오른쪽 Workflow의 준비 항목이 모두 완료되어야 추출 버튼이 활성화됩니다.

  1. 대상 선택

    활성 문서를 사용하거나 여러 RVT를 등록하고 View 선택 방식을 정합니다.

  2. 링크 계획

    직접 선택은 문서별 링크를 고르고, 빠른 방식은 모든 링크 포함 여부를 한 번에 정합니다.

  3. 3D View 선택

    조회 목록에서 체크하거나 쉼표·줄바꿈으로 정확한 View 이름을 입력합니다.

  4. 저장 폴더

    NWC 파일을 만들 폴더를 선택합니다.

  5. Export 옵션

    좌표, 파라미터, 형상 세부 수준 등을 정합니다.

  6. 실행·검증

    파일 생성과 크기·갱신 상태를 확인합니다.

가장 단순한 권장 설정 처음 실행은 활성 문서 또는 목록에서 직접 선택, Coordination 3D 한 개, Shared 좌표, Faceting Factor 1, 기존 파일 덮어쓰기 끔으로 시험합니다. 여러 파일에서 같은 View 이름을 반복 추출할 때만 빠른 방식을 사용합니다.

대상 RVT와 링크 로드 계획을 정합니다

활성 문서는 현재 Revit의 호스트 프로젝트 문서를 사용합니다. 여러 RVT는 별도 등록 창에서 파일을 선택하거나 드롭한 뒤 목록에서 직접 선택과 뷰 이름으로 일괄 추출 (빠른 방식) 중 하나를 고릅니다.

설정동작예시
활성 문서ActiveUIDocument.Document 기준의 현재 호스트 프로젝트를 바로 조회합니다. 패밀리 문서와 링크 문서는 대상에서 제외합니다.현재 작업 중인 Plant_A.rvt
여러 RVT · 목록에서 직접 선택등록 확인 시 RVT를 하나씩 열어 링크와 비템플릿 3D View 목록을 수집한 뒤 닫습니다. 이후 문서별 링크와 View를 직접 고를 수 있습니다.파일마다 View·링크 구성이 다를 때
여러 RVT · 뷰 이름으로 일괄 추출등록 시에는 RVT를 열지 않습니다. 쉼표 또는 줄바꿈으로 View 이름을 적고, 실제 추출할 때 각 RVT를 한 번씩 열어 정확히 같은 이름의 View를 찾습니다.모든 납품 RVT의 NWC_EXPORT View 추출
링크 모델 포함문서 단위로 Revit 링크를 NWC에 포함할지 결정합니다. 끄면 그 문서의 모든 링크를 Export 대상에서 제외합니다.MEP 단독 NWC에는 링크 제외
링크 체크체크한 링크는 Export 직전에 Reload하고, 체크하지 않은 Loaded 링크는 Unload합니다.ARCH만 포함하고 STRUCT·SITE 제외
현재 상태처음 조회했을 때의 Loaded / Unloaded 상태로 선택을 되돌립니다.수동 조정 전 상태 복구
전체 Reload / Unload현재 선택 문서의 모든 링크를 한 번에 포함 또는 제외합니다.간섭 검토용 전체 링크 포함
빠른 방식 · 모든 Revit 링크 포함빠른 방식은 문서를 미리 열지 않으므로 개별 링크를 선택하지 않습니다. 켜면 추출 시 각 RVT의 모든 링크를 Reload해 포함하고, 끄면 링크를 Reload하지 않고 NWC에서도 제외합니다.전체 링크를 동일 정책으로 처리하는 정기 배치
원래 링크 상태는 보존됩니다 Export를 위해 링크 상태를 잠시 바꾸더라도 작업 완료 후 원래 상태로 복원합니다. 복원 실패는 결과의 링크 오류 건수에 기록됩니다.

업무에 맞는 방식으로 3D View를 지정합니다

목록을 미리 조회한 경우에는 문서별 선택과 간편 뷰 설정을 사용할 수 있습니다. 빠른 방식은 View 이름만 입력해 두고 실제 추출 단계에서 각 문서의 정확히 같은 이름을 찾습니다.

목록에서 직접 선택

템플릿이 아닌 3D View만 표시됩니다. 왼쪽 문서 목록에서 RVT를 바꾸고, 오른쪽에서 이름 검색·전체 선택·선택 해제를 수행합니다.

  1. 문서 선택

    여러 RVT인 경우 각 문서의 View 수와 현재 선택 수를 문서 목록에서 확인합니다.

  2. 이름 검색

    NWC, Coordination 같은 View 이름 일부로 현재 문서 목록을 좁힙니다. 검색은 다른 문서의 기존 선택을 지우지 않습니다.

  3. View 체크

    선택한 View마다 NWC 파일 하나를 생성합니다. Perspective View는 별도 표시되므로 의도한 화면인지 확인합니다.

  4. 전체 선택 사용

    모든 문서 전체 선택은 조회된 모든 비템플릿 3D View를 선택합니다. 대량 생성이 될 수 있으므로 오른쪽 선택 View 수를 확인합니다.

  5. 간편 뷰 설정

    모든 조회 문서의 View 이름을 한 창에서 검색합니다. 정확히 같은 이름을 먼저 보여주고 비슷한 이름은 접힌 목록으로 구분합니다. 선택 적용은 현재 단계에 머물고, 적용 후 다음 설정은 선택을 반영한 뒤 3단계로 이동합니다.

뷰 이름으로 일괄 추출 (빠른 방식)

RVT 등록 단계에서 View 이름을 쉼표 또는 줄바꿈으로 입력합니다. 앞뒤 공백과 대소문자 차이는 정리해 중복 이름을 하나로 합치지만, 실제 View 검색은 이름 전체가 정확히 같은 비템플릿 3D View만 대상으로 합니다.

링크 처리모든 Revit 링크 포함을 켜거나 끄는 전역 정책만 사용합니다. 문서별·개별 링크 선택이 필요하면 직접 선택 방식으로 돌아갑니다.정기 배치에서 모든 파일에 같은 링크 정책 적용

작동 논리

문서와 View를 순서대로 처리하고 생성 파일을 검증합니다

여러 RVT를 동시에 열어두는 방식이 아니라 등록 순서대로 하나씩 처리합니다. 한 문서나 View가 실패해도 다음 대상은 계속 진행합니다.

  1. Exporter 확인

    현재 Revit에 Navisworks Exporter가 사용 가능한지 확인합니다. 없으면 실행 버튼이 준비되지 않습니다.

  2. 문서 열기

    활성 문서는 그대로 사용하고, 여러 RVT는 등록 순서대로 한 번씩 열어 처리합니다. 빠른 방식은 이 시점에 처음 문서를 엽니다.

  3. 링크 상태 기록

    직접 선택은 문서별 선택 계획에 따라 Reload 또는 Unload합니다. 빠른 방식은 모든 링크 포함 전역 설정을 적용합니다.

  4. View 해석

    직접 선택은 조회 때 저장한 View ID를 찾습니다. 빠른 방식은 입력한 이름과 정확히 일치하는 비템플릿 3D View를 현재 문서에서 찾고, 없는 이름은 건너뜀으로 기록합니다.

  5. View별 Export

    찾은 View마다 파일명 규칙과 옵션을 적용해 NWC를 생성합니다. 한 View가 실패하거나 없어도 다음 View와 다음 RVT를 계속 처리합니다.

  6. 파일 유효성 확인

    NWC가 실제로 존재하고, 크기가 0보다 크며, 실행 시작 뒤 갱신됐는지 확인합니다. 파일 크기가 연속 두 번 안정될 때 완료로 판단합니다.

  7. 링크 복원·문서 닫기

    링크를 원래 상태로 돌리고 배치 문서를 닫은 뒤 다음 RVT로 넘어갑니다.

Revit 2019의 Faceting Factor 값이 1이면 리본이나 Options Editor를 열지 않고 Revit API로 바로 추출합니다. 1이 아니면 Options Editor에 15개 Navisworks 옵션을 자동 반영하고 네이티브 값을 다시 읽어 일치 여부를 확인한 뒤 Export합니다. 활성 문서 실행은 처음 선택한 문서가 그대로 활성 상태인지 확인하며, 여러 RVT는 문서·View를 차례로 활성화한 뒤 작업 전 문서로 돌아옵니다. 이 네이티브 작업은 동시에 두 개 실행할 수 없습니다.

NWC 결과 Excel은 한 파일로 저장되며 한글/영문과 일반/빠른 저장을 선택합니다. RVT별 Excel 분리는 제공하지 않습니다.

주기별 NWC 결과를 비교하려면 이전 배포 폴더와 이번 Export 폴더가 준비된 뒤 NWC 용량 비교 검토를 사용합니다. 파일명, 용량, SHA-256, 신규·누락·객체 없음 상태를 한 화면에서 확인할 수 있습니다.

  • 저장 폴더의 쓰기 권한과 여유 공간 확인
  • 기존 파일 덮어쓰기 여부를 의도대로 선택
  • Faceting Factor를 높이기 전 샘플 한 개로 용량 확인
