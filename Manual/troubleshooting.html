문제 해결

먼저 확인할 지점을 좁히세요

3.0에서 자주 헷갈리는 공유파라미터, RVT 등록, 결과창, 업데이트 문제를 업무 흐름 기준으로 정리했습니다.

공유파라미터 목록이 비어 있음

Revit의 관리 > 공유 매개변수에서 TXT가 먼저 연결되어 있어야 합니다. KKY Tool 3.0은 별도 TXT 선택 기능을 제공하지 않습니다.

RVT 등록이 안 됨

여러 RVT 검토는 RVT 등록 창에서 파일을 추가합니다. 드래그 등록이 안 되면 버튼으로 추가하고, 경로에 접근 권한이 있는지 확인합니다.

활성 문서 검토가 안 됨

활성 Revit 문서가 호스트 문서인지 확인합니다. 링크 문서는 활성 문서 검토 대상으로 사용하지 않습니다.

Excel 저장 창이 보이지 않음

결과창 뒤에 저장 창이 숨어 있지 않은지 확인합니다. 3.0에서는 결과창과 저장 창의 포커스가 겹치지 않도록 조정 중입니다.

업데이트 확인 실패

회사망 또는 보안 정책에서 https://update.zerokky.com 접근을 막는지 확인합니다. 아래 상태 표에서 JSON 경로 접근도 확인할 수 있습니다.

2.37과 3.0 혼동

두 버전 모두 관리자용 애드인입니다. Stable 2.37은 초기 레이아웃 계열의 마지막 버전이며, 3.0은 UI 개편과 기능 추가가 반영된 버전입니다. 설치 경로와 파일명은 채널별로 구분됩니다.

서버 경로 상태

GitHub Pages에 올라가는 핵심 JSON 경로가 열리는지 확인합니다.
