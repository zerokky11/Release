공통 작업 흐름

여러 기능을 준비할 때 달라진 점

기능별 판정 논리와 별개로, 반복해서 쓰는 선택·저장·필터 흐름을 정리했습니다.

01

전체 선택

BQC 검토 또는 일반 도구 목록에서 현재 그룹의 선택 가능한 기능을 한 번에 추가합니다. 검색 결과만 선택하는 버튼이 아니라 해당 그룹 전체를 대상으로 합니다.

예시BQC 전체 기준을 한 번에 준비한 뒤 필요 없는 기능만 선택 해제합니다.

02

즐겨찾기 세트 파일

현재 즐겨찾기 세트의 이름, 선택 기능, 기능별 설정을 .kkyfav.json 파일로 저장하거나 다시 불러옵니다. 비어 있는 파일을 불러오면 현재 세트를 비웁니다.

예시프로젝트 공통 BQC 세트를 팀 폴더에 저장하고 다른 PC에서 같은 설정으로 불러옵니다.

03

공통 필터 적용

공통 설정의 포함·제외 필터는 해당 기능이 지원하는 대상 수와 실제 판정에 같은 기준으로 적용됩니다. 추가 파라미터는 판정 조건이 아니라 결과 Excel의 참고 열입니다.

예시Category=Pipe Curves 포함 필터를 두면 대상 수와 실제 검토가 모두 배관 곡선 기준으로 맞춰집니다.

여러 RVT · EXCEL

검토를 시작하기 전에 저장 방식을 선택합니다

파일이 많은 작업에서 결과를 메모리에 계속 쌓지 않도록, 대상 RVT 등록 창에서 Excel 생성 시점을 먼저 정할 수 있습니다.

01

실행 후 직접 저장

기존 방식입니다. 검토가 끝난 뒤 결과창을 열어 한글/영문과 한 파일/파일별 저장을 직접 선택합니다. 결과를 다시 살펴보거나 여러 기능의 Excel을 차례로 저장할 때 사용합니다.

예시3개 RVT의 결과를 화면에서 비교한 뒤 필요한 기능만 Excel로 내보냅니다.

02

기능별 통합 Excel 순차 저장

검토 전에 폴더를 선택하고, 기능마다 통합 Workbook 하나를 만든 뒤 RVT 결과를 완료 순서대로 추가합니다. 같은 이름이 있으면 _2처럼 번호를 붙입니다.

예시bqc_gridlevelconsistency_20260805_143000.xlsx 한 파일에 선택한 RVT의 Grid/Level 결과를 순서대로 기록합니다.

03

RVT별 Excel 즉시 저장

RVT 하나의 검토가 끝날 때마다 기능별 파일을 바로 저장하고 해당 결과 캐시를 해제합니다. 대상 파일 수가 많고 파일별 납품 결과가 필요할 때 적합합니다.

예시Plant_A_GridLevel정합성검토_03EA.xlsx를 저장한 뒤 Plant_A 결과를 해제하고 다음 RVT를 처리합니다.

04

저장 폴더·언어·열 너비

자동 저장 두 방식은 실행 전에 저장 폴더를 선택합니다. 폴더 선택을 취소하면 검토도 시작하지 않습니다. 한글/영문은 마지막 내보내기 언어 설정을 따르며, 열 너비 자동 맞춤을 끄면 대용량 결과를 더 빠르게 저장합니다.

참고활성 문서 검토는 이 자동 저장 방식을 사용하지 않고 결과창에서 직접 저장합니다. 자동 저장 결과창은 이미 저장된 폴더를 여는 용도로 표시됩니다.

일반 기능 결과 저장

실행 후 직접 저장에서는 한글/영문과 한 파일/파일별 저장을 조합할 수 있습니다. 각 상세 페이지에서 기능별 결과 항목과 실제 파일명 규칙을 확인할 수 있습니다.
