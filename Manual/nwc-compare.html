NWC 용량 비교 검토

이전 주기와 현재 주기의 NWC 또는 객체 없음 TXT를 파일명으로 짝지어 용량·SHA-256 변화를 찾고, 동·공종처럼 업무에 필요한 분류로 결과를 묶어 확인합니다.

처음부터 실행하기 판정 논리 보기
입력기준 / 현재 폴더
대상.nwc / .txt
판정용량 · SHA-256
결과화면 집계 + Excel
빠른 시작

두 폴더를 정한 뒤 분류와 판정 기준을 확인합니다

이 기능은 RVT를 다시 열거나 NWC를 생성하지 않습니다. 이미 만들어진 이전 결과 폴더와 이번 결과 폴더를 직접 비교합니다.

  1. 기준 폴더

    승인했거나 직전에 배포한 NWC/TXT 폴더를 선택합니다.

  2. 현재 폴더

    이번 주기에 새로 만든 NWC/TXT 폴더를 선택합니다.

  3. 판정 기준

    허용 변화율, 하위 폴더, SHA-256 확인 여부를 정합니다.

  4. 분류 구성

    동·공종 등 결과를 묶어 볼 축과 파일명 규칙을 입력합니다.

  5. 비교 실행

    오른쪽의 NWC/TXT 비교 실행을 누릅니다.

  6. 결과 저장

    상태별로 확인한 뒤 결과 Excel을 내보냅니다.

처음 실행할 때 검토 필요 기준은 기본값 5%, 하위 폴더 포함은 끔, 같은 용량 SHA-256 확인은 켬으로 시작하는 편이 좋습니다. 먼저 소규모 폴더로 파일명 짝이 의도대로 잡히는지 확인합니다.

비교 폴더와 판정 기준을 설정합니다

두 폴더에서 확장자가 .nwc 또는 .txt인 파일만 읽습니다. 파일명은 대소문자를 구분하지 않지만, 확장자를 뺀 나머지 이름은 정확히 같아야 한 모델로 묶입니다.

설정의미예시
기준 NWC/TXT 폴더변경 전 상태입니다. 지난 승인본이나 지난 주기 결과를 선택합니다.D:\Coordination\2026-07-13
현재 NWC/TXT 폴더변경 후 상태입니다. 이번 주기에 생성한 결과를 선택합니다.D:\Coordination\2026-07-20
검토 필요 기준 (%)용량 증감률의 절댓값이 이 값을 초과하면 검토 필요입니다. 같거나 작으면 허용 범위입니다.기준 100 MB, 현재 106 MB, 기준 5% → 검토 필요
하위 폴더 포함켜면 선택 폴더 아래의 모든 하위 폴더까지 재귀적으로 찾습니다. 같은 논리 이름이 여러 개면 중복으로 판정될 수 있습니다.동별 하위 폴더까지 한 번에 비교
같은 용량도 SHA-256 확인켜면 파일 크기가 같아도 내용이 다른 NWC를 찾습니다. 파일 수와 용량이 많으면 비교 시간이 늘어납니다.184 MB ↔ 184 MB지만 해시가 다르면 검토 필요
파일명 본체가 비교 키입니다 A01_MEP.nwc와 A01_MEP.txt는 같은 모델입니다. A01_MEP.nwc와 A01_MEP_객체없음.txt처럼 본체가 다르면 별도 모델로 읽으므로, 두 주기의 파일명과 접미사 규칙을 동일하게 유지해야 합니다.

업무에 맞는 분류 축을 직접 구성합니다

기본 축은 동, 공종, 파일입니다. 동과 공종은 예시일 뿐이며 축을 추가·삭제·이름 변경·순서 이동할 수 있습니다. 파일 축은 논리 파일명을 자동으로 표시하는 고정 축입니다.

항목입력 방법예시와 결과
헤더 이름결과 필터, 그룹 집계, Excel 열에 표시할 이름입니다.동, 공종, 구역, 협력사
파일명 판정 규칙분류값=키워드1|키워드2 형식을 사용하고, 여러 분류값은 세미콜론 또는 줄바꿈으로 구분합니다.A동=A01|A02; B동=B01|B02
키워드 매칭확장자를 뺀 파일명에 키워드가 포함되는지 대소문자 구분 없이 확인합니다. 위에서부터 처음 일치한 규칙을 사용합니다.A01_MEP → 동 A동
일치하지 않는 파일분류값을 빈칸으로 둡니다. 결과 표에서 직접 입력하거나 분류표 Excel로 채울 수 있습니다.예외 파일만 수동으로 공용 입력
순서 이동위·아래 버튼으로 축 순서를 바꿉니다. 화면 필터, 그룹 집계, 상세 표, Excel 열도 같은 순서를 따릅니다.공종 → 동 → 파일 순으로 변경
분류 구성 프리셋현재 축 이름·규칙·순서를 이름을 붙여 저장하고 다음 비교에서 다시 불러옵니다.주간 통합 NWC 프리셋
분류표 Excel

비교된 파일 목록을 내보내 분류값을 채울 수 있습니다

분류표 버튼은 비교 결과가 생긴 뒤 활성화됩니다. 현재 결과의 파일명을 행으로 내보낸 다음, 사용자 정의 축의 값을 채워 다시 가져옵니다.

단계동작확인 사항
분류표 내보내기NWC_Classification_yyyyMMdd_HHmmss.xlsx 한 파일을 만듭니다.첫 열은 파일명, 뒤에는 파일 축을 제외한 사용자 정의 축이 이어집니다.
값 입력파일명은 유지하고 동·공종·구역 등의 빈 셀만 채웁니다.규칙으로 이미 채워진 값도 필요하면 수정할 수 있습니다.
분류표 가져오기첫 번째 시트를 읽고 현재 비교 결과의 논리 파일명과 매칭합니다.경로와 .nwc/.txt 확장자는 무시합니다.
파일명 열파일명 외에도 모델 파일, NWC 파일, File Name, Model File, NWC File, File을 인식합니다.파일명 열이 없으면 가져오기를 중단합니다.
일치하지 않는 행현재 결과에 없는 파일명은 건너뜁니다. 같은 파일명이 두 번 나오면 첫 행만 사용하고 중복 건수로 알립니다.완료 메시지에서 적용·건너뜀·중복 건수를 확인합니다.

Excel에 일부 분류 열이 없어도 오류로 중단하지 않고 존재하는 열만 반영합니다. 축 이름을 바꾼 뒤에는 새 양식을 다시 내보내는 것이 안전합니다.

작동 논리

파일명, 출력 종류, 용량과 해시 순서로 판정합니다

먼저 확장자를 제외한 파일명으로 기준·현재 파일을 짝짓고, 중복과 존재 여부를 확인한 뒤 NWC 용량과 SHA-256을 비교합니다.

상태판정 조건예시
정상NWC 용량이 같고, SHA-256 확인을 켰다면 해시도 같습니다. 해시 확인을 끈 경우 같은 용량만으로 정상 처리합니다.184 MB ↔ 184 MB, 해시 동일
허용 범위NWC 용량이 바뀌었지만 증감률 절댓값이 검토 기준 이하입니다.96 MB → 99 MB, +3.13%, 기준 5%
검토 필요변화율이 기준을 초과하거나, 같은 용량의 해시가 다르거나, 기준 TXT에서 현재 NWC로 바뀌었습니다. 해시 계산 오류도 여기에 포함됩니다.210 MB → 185 MB, -11.9%
객체 없음현재 파일이 TXT입니다. 기준이 NWC였으면 객체가 사라진 변화이고, 기준과 현재가 모두 TXT여도 같은 상태로 집계합니다.기준 NWC → 현재 TXT
신규기준에는 없고 현재 폴더에 NWC가 새로 생겼습니다.B01_MEP.nwc 신규
누락기준에는 있었지만 현재 폴더에서 같은 논리 이름의 NWC/TXT를 찾지 못했습니다.B01_STR 현재 결과 없음
중복같은 논리 이름의 NWC/TXT가 기준 또는 현재 한쪽에 두 개 이상 있습니다.하위 폴더 두 곳에 A01_MEP.nwc 존재
  1. 파일 수집

    선택한 폴더 또는 하위 폴더에서 NWC와 TXT만 읽습니다.

  2. 논리 이름 구성

    경로와 확장자를 제외한 파일명으로 기준·현재 인덱스를 만듭니다.

  3. 중복·존재 판정

    중복, 신규, 누락을 먼저 결정합니다.

  4. 출력 종류 판정

    현재 TXT는 객체 없음, 기준 TXT에서 현재 NWC로 바뀌면 검토 필요입니다.

  5. 용량·해시 판정

    NWC끼리는 용량 변화율과 선택한 SHA-256 조건을 적용합니다.

  6. 분류·집계

    사용자 규칙과 수동 입력값을 적용해 필터와 그룹 집계를 만듭니다.

상태별 건수에서 모델 상세까지 내려가며 확인합니다

결과 상단의 상태 버튼은 바로 필터로 동작합니다. 그 아래에서 분류 축 순서대로 조건을 좁히고, 그룹 집계와 모델별 상세를 같은 화면에서 확인합니다.

영역표시 내용사용 방법
상태 요약전체, 정상, 허용 범위, 검토 필요, 객체 없음, 신규, 누락, 중복 건수상태 카드를 눌러 해당 결과만 표시
순서별 필터상태와 사용자 정의 분류값, 파일명 검색공종 MEP + 동 A동처럼 조합
그룹 집계분류 조합별 전체·검토·객체 없음·신규·누락 건수문제가 많은 동·공종을 먼저 파악
모델별 상세기준/현재 출력, MB, 증감 MB·%, 상태, 메시지원인이 필요한 개별 파일 확인
분류값 직접 입력파일 축 외의 분류 셀은 화면에서 수정 가능규칙에 걸리지 않은 예외 파일 보정

실행 전 점검

이름과 폴더 범위를 먼저 확인합니다

  • 기준 폴더가 변경 전 승인본인지 확인
  • 현재 폴더가 이번 주기 결과인지 확인
  • 두 폴더의 파일명 본체 규칙이 동일한지 확인
  • 하위 폴더 포함 시 같은 이름이 중복되지 않는지 확인

  • 대용량 파일이 많으면 SHA-256 소요 시간 고려
  • 분류 축 순서가 원하는 Excel 열 순서와 같은지 확인
  • 규칙 미일치 파일은 화면 또는 분류표 Excel로 보정
