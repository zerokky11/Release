중앙 설정 관리

KKY Tool 사용자 접근 정책과 Family Browser 관리 폴더를 한 화면에서 관리합니다. 두 설정은 기존 공개 경로에 각각 저장됩니다.

관리자 인증

설정 편집 화면을 열려면 관리자 비밀번호를 입력하세요.

KKY Tool

사용자 접근 정책

kky-tool/user-access.json에 저장되는 외부 사용자 제한 설정입니다.

user-access.json

한 줄에 하나씩 입력합니다. 예: KCIM

대소문자를 구분하지 않고 이름 일부가 일치하면 차단합니다. 허용 목록보다 먼저 적용됩니다.

허용 키워드와 별개로 정확히 일치하는 사용자 이름입니다. 차단 키워드에 걸리면 이 목록에 있어도 차단됩니다.

Family Browser

관리 폴더와 작업 기록 저장소

표준·권한의 원본 관리 폴더를 지정합니다. 작업자의 접근 범위가 다르면 아래에서 센트럴 파일 위치별 기록 저장소를 따로 연결합니다.

bootstrap.json

발급 후 경로 저장을 누르고, 해당 그룹 사용자에게만 전달하세요. Family Browser의 중앙 설정 연결 주소로 지정하면 그 그룹 설정만 읽습니다. 주소를 아는 사람은 설정을 읽을 수 있으므로 외부에 공개하지 마세요. 다시 발급하면 저장 시 이전 주소의 새 조회가 차단됩니다. 이미 받은 설정은 실행 중인 클라이언트에 캐시될 수 있습니다.

기존 설치본과의 호환을 위해 기본 그룹은 기존 공개 설정 주소로도 제공됩니다. 다른 그룹의 전체 매핑과 연결 키는 관리자 인증 후에만 조회됩니다. 그룹 연결은 네트워크 폴더의 실제 읽기·쓰기 권한을 대신하지 않습니다.

예: \\server\BIM\FamilyBrowser. 분리 저장을 사용하지 않으면 작업자도 이 위치의 기록 폴더에 접근할 수 있어야 합니다.

자동 생성되는 연결 식별자입니다. 같은 관리 그룹을 유지하는 동안 바꾸지 않습니다.

드라이브 문자는 PC마다 다르므로 \\서버\공유폴더\하위폴더 형식으로 등록합니다. 예: H 드라이브의 센트럴 폴더 → H 드라이브 안의 전용 기록 폴더. G 드라이브도 별도 저장소로 추가합니다.

홈페이지 저장과 실제 저장소 연결은 별도입니다. 새 설정을 지원하는 Family Browser에서 작업자 설정을 게시해야 합니다. 구형 설치본은 여러 그룹을 구분하지 못하므로 함께 전환하세요. 관리자 통합 수집은 아직 준비 중이며 기존 기록을 자동 이동·삭제하지 않습니다.

관리 경로와 작업자 기록 경로는 어떻게 다른가요?

최종 기록: 분리 저장을 끄면 원본 관리 폴더의 기존 기록 경로를 유지합니다. 켜면 권한/차단에 등록된 센트럴 파일의 경로와 저장소 대상 범위를 대조해, 해당 저장소 아래의 Revit 버전·프로젝트별 폴더에 기록합니다.

PC 임시 보관: 전송 대기 기록은 작업자 PC의 %LOCALAPPDATA%\KKY\FamilyBrowser\PendingTracking에서 보관합니다. 이 위치는 관리자가 함께 조회하는 최종 저장소가 아닙니다. 공유 위치에 접근할 수 있어야 전송을 완료할 수 있습니다.

예비 경로: 같은 공유 폴더의 다른 접속 주소나 장애 시 대체 주소입니다. 서로 다른 폴더를 등록하면 PC마다 저장 위치가 달라질 수 있으며, 기록을 자동으로 합쳐 주지 않습니다.

연결 확인: 관리 그룹 ID와 저장소 ID가 식별파일과 일치해야 전송합니다. 관리 폴더에 접근하지 못하는 작업자는 접근 가능한 기록 저장소의 읽기 전용 작업자 설정을 받습니다. 저장소가 끊기거나 ID가 다르면 로컬에 대기하며 다른 저장소로 우회하지 않습니다. 표준 RVT·이미지의 원본 읽기 권한은 별도로 필요합니다.

폴더 권한: 저장소의 Config와 식별파일은 관리자만 수정하고 작업자는 읽기만 허용하세요. 프로젝트 기록 하위 폴더에는 작업자의 기록 권한을 부여합니다. ID는 암호가 아니며 서버 권한 설정을 대신하지 않습니다. 프로그램이 만든 파일·폴더를 임의로 이동하거나 삭제하지 마세요.
