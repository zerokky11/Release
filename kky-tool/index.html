관리자

중앙 설정 관리

KKY Tool 사용자 접근 정책과 Family Browser 관리 폴더를 한 화면에서 관리합니다. 두 설정은 기존 공개 경로에 각각 저장됩니다.

관리자 인증

설정 편집 화면을 열려면 관리자 비밀번호를 입력하세요.

KKY Tool

사용자 접근 정책

kky-tool/user-access.json에 저장되는 외부 사용자 제한 설정입니다.

user-access.json

한 줄에 하나씩 입력합니다. 예: KCIM

대소문자를 구분하지 않고 이름 일부가 일치하면 차단합니다. 허용 목록보다 먼저 적용됩니다.

허용 키워드와 별개로 정확히 일치하는 사용자 이름입니다. 차단 키워드에 걸리면 이 목록에 있어도 차단됩니다.

Family Browser

공유 관리 폴더

첫 번째 경로를 기본으로 사용하고, 접근할 수 없으면 아래 예비 경로를 순서대로 확인합니다.

bootstrap.json

예: I:\FamilyBrowser\ProjectA. 각 경로 아래의 Config, Requests, Registry, Snapshots, Thumbnails 폴더를 사용합니다.

분

권한, 표준 라이브러리, 프로젝트 규칙 등 이 화면에서 편집하지 않는 기존 값은 그대로 보존합니다.
