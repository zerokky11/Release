KKY Tool Hub

Revit 납품 전 검토와 반복 정리 작업을 한 곳에서 실행하는 실무 보조 도구입니다.

BQC 검토, 파라미터 확인, 패밀리 타입 적합성 검토, 링크/웍셋 관리, 엑셀 결과 정리를 Hub 안에서 선택해 실행할 수 있습니다.

이 페이지에서는 최신 설치 파일, 업데이트 내역, 매뉴얼, 기능 요청 현황을 함께 확인합니다.

납품 전 검토

BQC 검토 흐름

12개
  • RVT 정리 (납품용)납품 파일 작성을 위한 뷰 정리, 불필요 항목 제거(Purge), 검토용 속성 추출
  • 조건별 객체 대상 속성 추출조건식으로 객체를 추려 지정 속성, 좌표, 선형 정보를 추출
  • 파라미터 연속성 검토연결된 MEP 객체의 파라미터 연속성 검토
  • 레벨 영역별 파라미터 검토선택한 레벨 영역 기준 파라미터 일치 여부 검토
  • 패밀리 타입 적합성 검토기준 엑셀의 카테고리/패밀리/타입 조합 비교
  • 속성 모수 검토파라미터별 기준값 엑셀을 기준으로 입력값 오/탈자 여부 검토
  • 미연결 검토커넥터 미연결 상태와 선택 시 중심축 연결 오류를 함께 검토
  • 탭/분기 축 틀어짐 검토배관/덕트 중심축 기준 탭/분기 피팅 축 검토
  • 중복 / 자체 간섭 검토여러 RVT 대상 중복 검토 또는 자체 간섭 검토
  • 웍셋 배정 검토기본 웍셋(Workset1) 또는 입력한 특정 웍셋 기준 검토
  • 프로젝트 파라미터 중복 검토추가된 프로젝트 파라미터 이름 중복 검토
  • 파라미터 누락 검토공유 텍스트 파라미터 누락 여부와 예외 규칙 검토

유틸리티 기능

11개
  • 중복 / 자체 간섭 검토활성 문서 또는 선택 RVT에서 중복 객체와 자체 간섭 검토
  • 패밀리 공유파라미터 추가/연동복합 및 하위 패밀리에 지정 파라미터 추가/연동
  • Segment-PMS 비교 검토PMS 양식 기준 Segment OD, ID 비교 검토
  • 파라미터 수정기조건 기반 필터링 대상으로 파라미터 값 일괄 입력
  • Revit 링크 경로 추출/재지정닫힌 RVT의 링크 경로 추출 및 엑셀 기준 반영
  • 노즐코드 KTA 단일화접수받은 KTA 양식을 하나의 시트 양식으로 추출
  • 파라미터 GUID 검토 및 정리프로젝트/패밀리 파라미터 GUID 검토 및 삭제 기준 정리
  • 패밀리 공유파라미터 연동 검토복합 패밀리와 하위 패밀리 파라미터 연동 여부 검토
  • 기준점/북각 추출RVT의 프로젝트 기준점, 측량 기준점, 북각 값 추출
  • 링크 기본 웍셋 점검/적용Revit 링크의 열려 있는 웍셋 현황 점검 및 기본 웍셋(Workset1) 적용
  • 프로젝트 파라미터 일괄 추가프로젝트 파일에 지정 파라미터 일괄 추가
