홈 화면에서 먼저 운영 상태를 확인합니다

최신 홈 화면은 목록을 바로 여는 화면이 아니라, 표준 원본과 프로젝트 기준선이 준비됐는지 확인하고 다음 작업으로 이동하는 컨트롤 센터입니다.

표준 RVT 원본 상태

선택한 공종의 표준 RVT가 마지막 승인 스캔과 같은지 확인합니다. 원본이 바뀌었다면 목록을 사용하기 전에 다시 스캔해야 합니다.

프로젝트 이름 카탈로그 추적

패밀리·패밀리 타입·시스템 타입 이름의 현재 기준선과 추가·삭제·외부 변경 건수를 보여줍니다.

표준 항목

현재 공종에서 사용할 수 있는 승인 패밀리와 시스템 타입 수를 합산합니다.

요청

열린 요청과 처리 중인 요청을 표시해 관리자 후속 작업이 남았는지 알려줍니다.

미등록 항목

현재 프로젝트에는 있지만 승인 표준 목록에서 찾을 수 없는 패밀리와 타입 수입니다.

로드 / 업데이트

새로 로드할 수 있는 항목과 관리자 업데이트가 가능한 기존 항목을 구분합니다.

운영 준비

정책, 표준 RVT, 요청 저장소 등 실행에 필요한 관리 경로가 모두 준비됐는지 요약합니다.

공종별 현황 · 최근 업데이트 · 다음 작업 화면 아래쪽에서는 공종별 표준 수와 요청 상태를 비교하고, 최근 표준 반영 기록을 확인한 뒤 라이브러리·모델 검사·요청 같은 다음 업무로 바로 이동합니다.
왼쪽 지원 메뉴 업데이트 확인은 설치된 버전과 배포 정보를 확인하고, 홈페이지와 매뉴얼은 현재 설정된 운영 URL을 기본 브라우저로 엽니다. 라이브러리 데이터 갱신 버튼과는 역할이 다릅니다.

무엇을 해결하는가

프로젝트마다 제각각인 로드 경로와 기억에 의존한 표준 판단을 줄이고, 관리자가 승인한 표준만 사용자에게 보여주는 것을 목표로 합니다.

승인 목록만 표시

관리자가 연결한 표준 RVT 스냅샷과 승인 Excel/JSON 목록에 포함된 항목만 탐색합니다.

패밀리와 시스템 타입 분리

로드 가능한 패밀리와 프로젝트 내부 시스템 타입을 각각의 적용 방식으로 처리합니다.

현재 모델 비교

선택한 공종 기준과 현재 활성 프로젝트를 비교하고 검토 항목을 Excel로 저장합니다.

변경 이력 추적

프로젝트 이름 목록과 요소 생성·수정·삭제 이력을 저장·동기화 시점에 확정해 외부 변경을 찾습니다.

요청 흐름 연결

없는 패밀리, 없는 시스템 타입, 더 나은 프로젝트 항목의 표준 업데이트를 요청합니다.

파일별 명령 차단

지정된 RVT에서 Revit 기본 패밀리 명령과 타입 변경 명령을 정책에 따라 막습니다.

캐시 우선 시작

대시보드를 열 때 표준 RVT를 다시 스캔하지 않습니다. 무거운 검사는 사용자가 직접 실행합니다.

처음 사용과 일상 업무는 순서가 다릅니다

처음 한 번은 관리자가 기준 데이터를 준비하고, 그 다음부터 일반 사용자가 승인 목록을 탐색합니다.

최초 준비: 표준 RVT 연결 → 전체 정밀 스캔 → 표준 목록 Excel 연결 이 세 단계가 끝나야 패밀리 / 시스템 타입 목록이 표시됩니다. 설치 직후 목록이 비어 있다면 처음 설정 매뉴얼부터 확인합니다.

준비 후 기본 업무 흐름

기준 데이터가 준비된 뒤에는 아래 순서로 작업합니다.

  1. 기준 확인상단에서 공종과 등록된 표준 대상이 맞는지 확인합니다.
  2. 항목 탐색패밀리 또는 시스템 타입 탭에서 검색·필터링합니다.
  3. 상태 판단로드 가능, 업데이트 가능, 표준과 다름 등의 상태를 확인합니다.
  4. 로드 또는 적용선택한 신규 항목을 현재 활성 프로젝트에 반영합니다.
  5. 저장 또는 동기화성공한 저장·다른 이름으로 저장·동기화 후 추적 상태가 확정됩니다.
표준 대상 선택이 먼저입니다. 공종별 표준에 같은 이름의 항목이 있을 수 있으므로 모델 검사와 업데이트 전에 현재 선택 기준을 확인해야 합니다.

상세 매뉴얼

처음 설치했다면 처음 설정부터, 이미 목록이 보인다면 필요한 업무 페이지부터 읽으면 됩니다.

처음 설정

표준 RVT 연결, 전체 정밀 스캔, 표준 목록 Excel 연결과 빈 목록 해결

 패밀리 / 시스템 타입

검색, 상세 필터, 선택 로드·적용, 상세 항목 창과 상태 해석

 현재 모델 검사

비교 기준, 검사 논리, 결과 해석과 Excel 파일 구조

 프로젝트 변경 추적

이름 기준선, 외부 변경 판정, 요소 변경 이력과 저장·동기화 경계

 추가 요청

없는 항목과 표준 업데이트 요청, 첨부파일, 진행 상태

 권한 / 차단

파일별 Revit 기본 명령 차단 대상과 파일 식별 방식

 관리자 설정

표준 RVT, 표시 목록, 스캔·스냅샷과 요청 저장소 구성

사용자와 관리자

일반 사용자

승인 목록 탐색, 신규 항목 로드·적용, 현재 모델 검사, 요청 등록과 진행 상태 확인을 수행합니다.

관리자

표준 RVT와 표시 목록을 연결하고 스캔하며, 기존 프로젝트 항목 업데이트와 요청 처리를 수행합니다.

파일 정책 적용 사용자

지정된 RVT에서는 Family Browser 외의 Revit 기본 명령 일부가 차단될 수 있습니다.

기존 항목 업데이트는 관리자 작업입니다. 일반 사용자가 라이브러리에서 직접 선택해 반영할 수 있는 상태는 기본적으로 로드 가능입니다. 이미 프로젝트에 있는 항목의 표준 업데이트는 관리자 흐름에서 처리합니다.

동작 범위와 확인 사항

  • 활성 프로젝트가 있어야 로드, 적용, 현재 모델 검사 기능을 실행할 수 있습니다.
  • 대시보드 열기와 탭 전환은 캐시된 등록 상태를 사용합니다. 표준 RVT 파일 확인과 정밀 스캔은 명시적인 버튼을 눌렀을 때 실행됩니다.
  • 카테고리가 다른 동일 이름 패밀리는 자동 덮어쓰지 않고 차단합니다.
  • 중복 위험이 있는 시스템 타입은 적용 전에 진단과 대상 확인이 필요합니다.
  • 화면에 표시되는 내부 경로와 디버그 로그는 관리자 모드에서만 보일 수 있습니다.
