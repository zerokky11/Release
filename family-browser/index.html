패밀리 브라우저 경로

Family Browser 관리 폴더를 한 곳에서 관리합니다

관리 폴더 후보 경로를 여러 개 등록하면 애드인이 위에서부터 접근 가능한 경로를 찾습니다.

성공한 경로는 PC에 기억되고, 다음 실행 때 그 경로를 우선 사용합니다.

서버 저장은 관리자 비밀번호로 동작합니다. GitHub 토큰은 브라우저에 노출되지 않습니다.

관리자 확인

설정 편집은 관리자만 사용합니다.

Revit에 로그인된 Autodesk 프로필 이름에 이 키워드가 포함된 사용자만 애드인 설정에서 관리자 모드를 켤 수 있습니다.

한 칸에 하나의 관리 폴더를 입력합니다. 예: I:\30. 협력사 전용폴더\00. BIM_KCIM\02. 패밀리\TEST

애드인은 이 폴더 아래의 Config, Requests, Registry, Snapshots, Thumbnails 폴더를 기준으로 사용합니다.
