권한 / 차단

특정 RVT에서 표준 라이브러리를 우회하는 Revit 기본 명령을 파일 단위로 차단합니다. 이 화면은 사용자 역할 목록이 아니라 현재 파일에 적용된 명령 가드 상태를 확인하는 곳입니다.

차단하는 명령 그룹

패밀리 로드 / 편집

Revit 기본 패밀리 로드와 프로젝트에서의 패밀리 편집 등 표준 라이브러리를 우회할 수 있는 명령을 묶어 제어합니다.

타입 추가 / 삭제 / 이름 변경

시스템 타입과 프로젝트 타입 구조를 임의로 변경할 수 있는 기본 명령을 묶어 제어합니다.

Family Browser 흐름

승인 목록의 로드·적용, 현재 모델 검사와 요청 등록은 정책에 맞는 표준 경로로 계속 사용합니다.

전체 Revit을 잠그는 기능이 아닙니다.관리자가 지정한 대상 RVT와 선택한 명령 그룹에만 적용됩니다. 다른 문서와 일반 모델링 명령은 별도입니다.

대상 파일을 식별하는 방식

문서 상태식별 기준의도
중앙 모델중앙 RVT 경로중앙 파일 자체를 정확히 정책 대상과 연결
로컬 모델연결된 중앙 경로사용자별 로컬 파일명이 달라도 같은 중앙 정책을 적용
분리된 모델원본 RVT 파일명 보조 비교중앙 경로가 끊긴 경우 원본 이름을 기준으로 제한적으로 식별
분리된 모델은 이름 확인이 중요합니다.Detached 문서는 중앙 경로를 사용할 수 없으므로 원본 파일명 기준 보조 판단이 들어갑니다. 이름을 바꾼 사본은 관리자 확인이 필요합니다.

사용자 화면에서 확인할 것

  1. 권한 / 차단 탭을 엽니다.

    현재 활성 프로젝트와 파일별 권한 적용 사용 여부를 확인합니다.

  2. 현재 파일이 정책 대상인지 확인합니다.

    중앙 경로 또는 원본 파일 식별 결과가 관리자 지정 대상과 일치하는지 봅니다.

  3. 차단 명령 그룹을 확인합니다.

    패밀리 명령과 타입 변경 명령 중 어떤 그룹이 막혀 있는지 확인합니다.

  4. 표준 작업은 Family Browser에서 실행합니다.

    새 패밀리는 패밀리 탭, 새 시스템 타입은 시스템 타입 탭, 없는 항목은 요청 탭을 사용합니다.

명령이 차단되었을 때

  • 현재 프로젝트가 파일별 권한 적용 대상인지 먼저 확인합니다.
  • 필요한 항목이 승인 목록에 있으면 Family Browser 라이브러리에서 로드 또는 적용합니다.
  • 승인 목록에 없으면 추가 요청에서 패밀리·시스템 타입 요청을 등록합니다.
  • 프로젝트 항목이 표준보다 낫다고 판단되면 표준 업데이트 요청을 등록합니다.
  • 정책 대상이 아닌데 차단되었다면 중앙 경로와 원본 파일명을 관리자에게 전달합니다.

관리자 적용 원칙

파일 가드는 표준 라이브러리와 요청 흐름이 준비된 뒤 적용해야 합니다. 사용자가 필요한 항목을 얻을 수 없는 상태에서 먼저 차단하면 업무가 멈춥니다.

  1. 표준 RVT 준비공종별 기준을 등록하고 스캔합니다.
  2. 표시 목록 준비사용자가 선택할 승인 목록을 연결합니다.
  3. 요청 저장소 준비없는 항목을 요청할 공용 흐름을 연결합니다.
  4. 대상 RVT 등록중앙 경로와 차단 그룹을 정확히 지정합니다.
  5. 실제 문서 확인중앙·로컬·분리 문서에서 정책 일치를 검증합니다.
