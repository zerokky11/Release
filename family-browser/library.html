패밀리와 시스템 타입

관리자가 승인한 표준 목록에서 항목을 찾고, 현재 모델 상태를 확인한 뒤 신규 패밀리는 로드하고 시스템 타입은 적용합니다.

목록이 비어 있다면 사용법보다 초기 설정을 먼저 확인합니다.표준 RVT 연결, 전체 정밀 스캔, 표준 목록 Excel 연결이 모두 완료되어야 승인 목록이 표시됩니다. 처음 설정 매뉴얼 보기

사용 전 준비

활성 프로젝트

로드·적용 대상이 되는 Revit 프로젝트 문서가 활성 상태여야 합니다. 링크 문서는 대상이 아닙니다.

표준 대상

상단의 공종과 표준 대상이 현재 업무에 맞는지 확인합니다. 선택 대상에 등록·스캔된 표준 RVT가 필요합니다.

승인 표시 목록

관리자가 승인 Excel/JSON 목록을 연결하지 않았다면 일반 사용자 라이브러리는 비어 있을 수 있습니다.

현재 상태 갱신

대시보드 열기는 캐시를 사용합니다. 원본 표준이 바뀌었다면 관리자가 먼저 스캔을 갱신해야 합니다.

패밀리 로드

패밀리 탭은 승인된 로더블 패밀리를 검색하고 현재 모델에 없는 항목을 불러오는 화면입니다.

  1. 공종과 보기 범위를 확인합니다.

    상단 기준과 전체 / 모델 / 주석 보기 중 필요한 범위를 선택합니다.

  2. 이름 또는 카테고리로 찾습니다.

    검색창과 카테고리 트리를 함께 사용하고, 필요한 경우 상세 필터에서 상태를 좁힙니다.

  3. 행의 상태와 상세 항목을 확인합니다.

    항목을 열면 타입, 파라미터, 하위 패밀리, Lookup CSV/사이즈 테이블과 표준 차이를 확인할 수 있습니다.

  4. 로드 가능 항목을 선택합니다.

    체크박스로 필요한 신규 패밀리를 선택합니다. 기존 항목 업데이트는 이 버튼의 대상이 아닙니다.

  5. 선택 항목 로드를 실행합니다.

    카테고리와 표준 대상을 다시 확인한 뒤 현재 활성 프로젝트에 반영합니다.

카테고리 불일치는 차단됩니다.같은 이름이라도 표준과 프로젝트 카테고리가 다르면 자동 덮어쓰기하지 않습니다. 잘못된 대상을 선택했는지 먼저 확인합니다.

시스템 타입 적용

시스템 타입 탭은 표준 시스템 패밀리 종류와 타입 정의를 현재 모델의 기존 구조에 맞춰 적용합니다.

  1. 시스템 패밀리 종류를 확인합니다.

    덕트, 배관, 케이블 트레이처럼 항목이 속한 시스템 패밀리와 카테고리를 먼저 확인합니다.

  2. 검색과 상태 필터로 대상을 찾습니다.

    로드 가능, 업데이트 가능, 표준과 다름, 중복 위험, 검토 대상 등의 상태를 기준으로 좁힙니다.

  3. 의존 항목을 검토합니다.

    라우팅 프리퍼런스, 부품·클래스·카테고리, 크기 범위, 레이어 구성 등 적용에 필요한 의존성을 확인합니다.

  4. 선택 항목 적용을 실행합니다.

    현재 프로젝트에 만들 수 있는 신규 시스템 타입을 선택해 반영합니다. 적용 직전 의존 항목을 다시 검증합니다.

중복 위험은 자동 적용 대상이 아닙니다.동일 계열의 타입 이름이나 의존 관계가 충돌할 가능성이 있으면 진단 결과를 먼저 확인해야 합니다.

System Type 상세 구성 요소

관리자가 System Type 상세 구성 요소 비교 (Railing, Stair 등)를 켠 기준은 타입 이름과 일반 파라미터 외에 그 타입이 참조하는 내부 구성까지 비교합니다.

대상추가로 확인하는 내용읽는 방법
RailingTop Rail, Handrail, Rail Structure, Baluster와 참조 타입타입 이름이 같아도 구성 패밀리나 간격이 다르면 차이로 표시됩니다.
StairRun, Landing, Support 및 연결된 타입 설정계단 본체만 같고 Run 또는 Support가 다른 경우를 별도 차이로 확인합니다.
Curtain 계열Panel, Mullion 등 필수 의존 타입상세 비교 옵션과 관계없이 적용에 필요한 의존 항목을 점검합니다.
치수 값원본 값과 단위단위가 다른 환경에서도 저장된 단위와 변환 값을 기준으로 비교합니다.

상세 항목 창 읽기

목록 행의 상세 보기를 열면 대시보드와 별개로 이동 가능한 창이 열립니다. 이 창은 적용 전 표준 내용과 차이를 판단하는 용도입니다.

기본 정보

패밀리명, 카테고리, 타입 수, 현재 상태와 표준 기준을 확인합니다.

타입 / 파라미터

표준 스냅샷에 기록된 타입과 파라미터 구조를 확인합니다.

하위 패밀리

정밀 스캔에서 수집한 중첩 패밀리 메타데이터를 확인합니다.

CSV / 사이즈 테이블

패밀리 내부 Lookup CSV 또는 사이즈 테이블의 포함 여부와 차이를 확인합니다.

저장과 동기화

로드 또는 적용 성공만으로 추적 상태를 확정하지 않습니다. 문서에 실제로 남았다는 것이 확인되어야 최종 상태로 바뀝니다.

  • 일반 RVT: 저장 또는 다른 이름으로 저장이 성공하면 임시 상태를 확정합니다.
  • 워크셰어링 RVT: 중앙과 동기화가 성공하면 확정합니다.
  • 취소 또는 실패: 임시 상태를 유지하므로 다시 저장하거나 동기화해야 합니다.
  • 저장하지 않고 문서 닫기: 해당 작업의 임시 추적 정보는 버립니다.
