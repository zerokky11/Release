처음 사용 준비

패밀리 / 시스템 타입 목록은 설치 직후 바로 채워지지 않습니다. 관리자가 표준 RVT를 연결하고 전체 정밀 스캔을 완료한 뒤, 사용자에게 보여줄 표준 목록 Excel까지 연결해야 항목이 표시됩니다.

시작 전에 준비할 것

관리자 권한

표준 RVT 연결, 스캔 유지관리, 표준 목록 Excel 연결은 관리자 작업입니다. 버튼이 보이지 않으면 관리자 계정 또는 권한 설정을 먼저 확인합니다.

승인된 표준 RVT

팀에서 기준으로 사용할 .rvt 파일을 준비합니다. 공종별 표준을 사용한다면 건축·전기·소방·설비처럼 대상별 파일을 구분합니다.

표준 목록 Excel 또는 CSV

사용자 화면에 공개할 패밀리와 시스템 타입을 정리한 .xlsx 또는 .csv 파일을 준비합니다. Excel은 연결 중 사용할 시트를 선택합니다.

올바른 공종 대상

연결과 스캔은 현재 선택한 공종 / 라이브러리 대상에 저장됩니다. 작업을 시작하기 전에 화면의 현재 대상이 의도한 공종인지 확인합니다.

일반 사용자는 이 설정을 반복하지 않습니다.관리자가 한 번 준비하면 일반 사용자는 패밀리 / 시스템 타입 화면에서 승인 목록을 검색하고 로드·적용합니다. 목록이 비어 있다면 먼저 관리자에게 아래 세 단계의 완료 여부를 확인합니다.

처음 설정 순서

중간 단계를 건너뛰면 목록이 비어 있거나 상세 정보와 미리보기가 부족하게 표시될 수 있습니다.

  1. 관리자 ON상단 관리자 모드를 켜서 표준 관리 메뉴를 표시합니다.
  2. 대상 선택표준 모드와 공종 / 라이브러리 대상을 확인합니다.
  3. 표준 RVT 연결승인 RVT를 등록하고 빠른 스냅샷을 만듭니다.
  4. 전체 정밀 스캔Fingerprint, 파라미터, 미리보기와 의존 정보를 만듭니다.
  5. 표준 Excel 연결승인 목록을 가져와 실제 사용자 목록을 공개합니다.

1. 표준 모드와 현재 대상 확인

  1. Family Browser 상단에서 관리자 ON을 확인합니다.

    관리자 기능이 꺼져 있으면 표준 관리 메뉴와 연결·스캔 버튼이 나타나지 않습니다.

  2. 왼쪽 메뉴에서 표준 관리 또는 관리자 설정을 엽니다.

    1. 표준 기준 / 표시 목록 영역으로 이동합니다.

  3. 표준 모드를 선택합니다.

    공종별 표준 사용은 공종마다 다른 RVT와 목록을 연결합니다. 통합 표준 사용은 하나의 RVT를 공통 기준으로 사용합니다.

  4. 공종 / 라이브러리 대상을 선택합니다.

    예를 들어 설비 표준을 준비한다면 설비를 선택합니다. 이후 연결되는 RVT, 스캔, Excel 목록은 이 대상에 속합니다.

대상을 바꾸면 다른 목록이 보이는 것이 정상입니다.공종별 표준 사용 중에는 각 공종이 독립적인 기준 RVT와 승인 목록을 가집니다. 파일을 잘못된 대상에 연결했다면 해당 대상에서 등록/스캔을 초기화한 뒤 다시 연결합니다.

2. 표준 RVT 연결

  1. 기준 RVT 카드에서 표준 RVT 연결을 누릅니다.

    현재 대상 이름이 맞는지 한 번 더 확인합니다.

  2. 승인된 .rvt 파일을 선택합니다.

    임시 프로젝트나 작업 중인 납품 파일이 아니라 팀의 기준으로 관리할 표준 RVT를 선택합니다.

  3. 빠른 등록이 끝날 때까지 기다립니다.

    연결 단계에서는 빠른 스캔으로 등록 정보와 기본 스냅샷을 만듭니다. 결과 창에서 대상, 스캔 방식, 로드 가능 패밀리·타입 수, 시스템 타입 수를 확인합니다.

  4. 표준 RVT 기록이 미등록에서 파일명과 스캔 기록으로 바뀌었는지 확인합니다.

    등록이 완료되어도 아직 정밀 정보와 사용자 표시 목록은 준비되지 않았습니다.

표준 RVT 연결만으로 사용자 목록 준비가 끝나지 않습니다.연결 버튼은 빠른 등록을 수행합니다. 하위 패밀리 메타데이터와 3D 미리보기까지 갖추려면 다음 단계의 전체 정밀 스캔이 필요합니다.

3. 전체 정밀 스캔

  1. 기준 RVT 카드에서 관리 설정을 누릅니다.

    등록된 RVT, 마지막 스캔 상태, 파일 수정 기록과 스캔 유지관리 버튼이 표시됩니다.

  2. 전체 정밀 스캔을 누릅니다.

    최초 설정에서는 빠른 변경 확인이나 선택 패밀리 갱신이 아니라 전체 정밀 스캔을 사용합니다.

  3. 스캔 완료 메시지를 확인합니다.

    전체 RVT의 Fingerprint, 파라미터, 하위 패밀리 메타데이터, 3D 미리보기, 시스템 타입 정의와 의존 관계를 다시 만듭니다.

  4. 마지막 스캔 상태가 갱신되었는지 확인합니다.

    정밀 스캔은 표준 데이터의 내용과 미리보기를 준비하지만, 승인 Excel을 아직 연결하지 않았다면 일반 사용자 목록은 계속 비어 있을 수 있습니다.

버튼언제 사용하는가처음 설정에서 사용
전체 정밀 스캔최초 등록, 대규모 표준 변경, 전체 기준 재구축필수
빠른 변경 확인운영 중 표준 RVT 파일 수정 여부만 확인아님
선택 패밀리 정밀 갱신변경된 소수 패밀리만 다시 수집아님

4. 표준 목록 Excel 연결

이 단계가 사용자에게 보일 승인 목록을 결정합니다. 표준 RVT에 들어 있는 모든 항목을 자동 공개하지 않고, 연결한 Excel 또는 CSV에 있는 항목만 목록으로 만듭니다.

  1. 표시 표준 목록 카드에서 표준 목록 Excel 연결을 누릅니다.

    이 작업도 현재 선택한 공종 / 라이브러리 대상에 적용됩니다.

  2. .xlsx 또는 .csv 파일을 선택합니다.

    Excel 파일이면 이어서 워크시트 선택 창이 열립니다. 헤더와 승인 항목이 들어 있는 시트를 선택합니다.

  3. 가져오기 완료 메시지를 확인합니다.

    대상, 선택 시트, 가져온 패밀리/타입 수, 표시 대상 수가 나옵니다. 가져온 수가 0이면 시트와 헤더, 데이터 행을 다시 확인합니다.

  4. 표준 목록 상태가 연결됨과 행 수로 바뀌었는지 확인합니다.

    가져온 Excel은 공유 JSON과 목록 인덱스로 변환되고, 캐시된 표준 데이터에서 사용자 목록을 다시 구성합니다.

5. 목록 표시 확인

  1. 패밀리 메뉴를 엽니다.

    현재 대상의 승인 로더블 패밀리가 목록에 표시되는지 확인합니다.

  2. 시스템 타입 메뉴를 엽니다.

    Excel의 Category, Family, Type에 맞는 승인 시스템 타입이 표시되는지 확인합니다.

  3. 검색과 상세 창을 확인합니다.

    패밀리명 또는 타입명으로 검색하고, 상세 정보·파라미터·미리보기가 정밀 스캔 결과와 맞는지 봅니다.

  4. 일반 사용자 모드에서도 같은 승인 목록이 보이는지 확인합니다.

    관리자 전용 버튼과 내부 경로는 숨겨져도 승인 목록 자체는 동일하게 보여야 합니다.
