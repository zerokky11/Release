KKY Tool 3.x

새 작업대 UI와 확장 기능을 사용하는 현재 계열입니다.

현재 버전 받기
  1. 배포 준비3.0.2문서 기준 2026.07.31

    모델 정리와 반복 추출 흐름 보강

    3.0.1 이후 추가·수정된 기능을 현재 구현 기준으로 정리했습니다. 설치 파일과 자동 업데이트는 아직 3.0.1을 유지합니다.

    • 호스트와 Run 참조가 끊긴 객체를 검출·선택 삭제하고 전후 모델 객체 수를 대조하는 유령객체 제거를 BQC 기능에 추가했습니다.
    • 파라미터 연속성 검토에 값 일치 처리 매핑, 활성 문서·여러 RVT 값 스캔, Excel 양식 왕복을 추가하고 End + Dummy 제외 조건을 같은 패밀리명에 두 단어가 모두 있는 경우로 명확히 했습니다.
    • Schedule Export에서 파일 이름 포함을 선택하도록 바꾸고, 해당 객체 전체는 Element ID와 선택 Schedule의 표시 필드만 추출하도록 열 구성을 정리했습니다.
    • NWC Export에 모든 조회 문서의 View를 한 번에 고르는 간편 뷰 설정과, View 이름을 먼저 입력하고 실행 때 찾는 빠른 일괄 추출 방식을 추가했습니다.
    • 기능 전체 선택과 즐겨찾기 세트 .kkyfav.json 저장·불러오기를 추가하고, 공통 포함·제외 필터가 대상 수와 실제 검토에 같은 기준으로 적용되도록 맞췄습니다.
  2. 현재 배포3.0.12026.07.21

    공식 패키지 구성 정리

    BIA2 분석 기능을 정식 KKY Tool 패키지에서 분리하고, 나머지 공식 기능을 기준으로 설치 파일과 자동 업데이트 패키지를 다시 구성했습니다.

    • BIA2 분석 메뉴와 관련 구성 요소를 공식 배포본에서 제외했습니다.
    • 3.x 업데이트 피드와 설치 파일 버전을 3.0.1로 맞췄습니다.
    • Revit 2019, 2021, 2023, 2025, 2027 지원을 유지합니다.
  3. 정식 버전3.02026.07.20

    3.x 작업대와 주요 기능 정식 전환

    2.x의 기능 로직을 이어받되 화면 구조와 실행 흐름을 3.0 작업대 기준으로 다시 정리한 첫 정식 버전입니다.

    • 홈, 즐겨찾기, BQC 검토, 일반 도구, Schedule 도구, NWC Export를 한 작업대에서 이동하도록 구성했습니다.
    • 기능 선택 → 설정 → 대상 선택 → 실행 → 결과·Excel 흐름을 공통 UI로 정리했습니다.
    • 라이트·다크 테마와 Document Navigator를 추가했습니다.
    • Schedule 추출·입력, NWC 일괄 추출, NWC 결과 비교를 주요 업무 기능으로 포함했습니다.
    • Stable 2.x와 분리된 3.x 자동 업데이트 채널을 사용합니다.

KKY Tool Stable 2.x

최종 Stable 2.37
  1. 최종 Stable2.372026.07.09

    RVT 정리 안정성 보완

    일부 환경에서 RVT 정리의 Purge가 실행되지 않던 경우를 추가로 수정하고 홈 화면의 내부 사용자 관리 진입 항목을 제거했습니다.

  2. Stable2.362026.07.09

    RVT 정리 Purge 수정

    납품용 RVT 정리 과정에서 불필요 항목 제거가 정상적으로 이어지도록 Purge 실행 문제를 수정했습니다.

  3. Stable2.352026.06.10

    사용자 제한 정책 중앙 관리

    외부 사용자 제한 정책을 개별 설치 환경이 아닌 홈페이지 관리자 설정에서 관리하도록 변경했습니다.
