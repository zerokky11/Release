  1. 현재 배포3.0.162026.09.04

    RVT Nozzle 긴 설정 화면 스크롤 보완

    RVT Nozzle 정보 추출에서 파라미터 입력 항목이 길어져도 작은 Hub 창 안에서 설정을 끝까지 확인하고 입력할 수 있도록 화면을 정리한 버전입니다.

    • Nozzle Code, KTA, 모델링 검토의 RVT Nozzle 정보 추출 탭에서 파라미터 설정 영역만 독립적으로 위아래 스크롤할 수 있게 했습니다.
    • Hub 창을 최대화하지 않은 상태에서도 Utility, Lateral, Nozzle Code 매핑과 추가 패밀리·타입 키워드 등 아래쪽 설정이 화면 밖에 가려지지 않습니다.
    • 가로 스크롤은 숨기고 세로 스크롤 폭과 여백을 고정해, 설정을 움직일 때 주변 실행 영역의 폭이 흔들리지 않도록 했습니다.
    • Revit 2019, 2021, 2023, 2025, 2027 지원을 유지합니다.
  2. 정식 버전3.0.152026.09.02

    Foreline 모델링·Level 변경과 Nozzle 비교 보강

    링크 CAD 원형을 Revit 패밀리로 배치하는 모델링 기능과 Excel 지시로 여러 RVT의 Level을 변경하는 대량 작업 기능을 추가하고, KTA/RVT Nozzle 비교와 여러 파일 작업 진행 표시를 보완한 버전입니다.

    • CAD link 기반 Foreline 모델링을 추가했습니다. 활성 프로젝트의 링크 CAD에서 레이어별 수평 원형을 스캔하고, 중심 좌표·직경·검출 품질을 확인한 후보만 선택한 Level에 OneLevelBased 비호스트 패밀리로 배치합니다.
    • Foreline 배치 시 링크별 Base Level·Height, 패밀리 타입과 Diameter·Height·원본 CAD 레이어 파라미터를 매핑할 수 있습니다. 원 검출 허용오차와 직경 범위를 조정하며, 동일 출처 인스턴스는 기본적으로 건너뜁니다.
    • 프로젝트 파일 내 Level 변경을 추가했습니다. 등록 RVT로 전용 Excel 양식을 만든 뒤 Level 이름, 위/아래와 이동 거리(mm)를 작성하고 다시 검증한 실행 행만 파일별로 처리합니다.
    • Level 변경 결과는 RVT마다 별도 Excel로 저장합니다. 변경 전·후 표고와 Pin, 수정·삭제·추가·연결 변화, 영향 객체의 위치·Level·Host·연결, Revit 경고·오류와 저장·중앙 동기화 상태를 함께 기록합니다.
    • Nozzle Code, KTA, 모델링 검토는 KTA와 RVT 결과를 단순 존재 여부가 아니라 발생 행 수를 세는 다중집합으로 비교합니다. 수량 불일치, 한쪽 누락, 양쪽에서 유일한 Nozzle Code의 속성 차이, 동일 객체·객체 간·파일 간 중복과 원본 위치를 구분해 남깁니다.
    • 조건별 추출, 파라미터 수정, 프로젝트 파라미터 일괄 추가, Level 변경과 Nozzle 추출 등 여러 RVT 작업은 전체 파일 수와 현재 파일·처리 단계를 실행 중 바로 갱신합니다.
    • Revit 2019, 2021, 2023, 2025, 2027 지원을 유지합니다.
  3. 정식 버전3.0.142026.08.28

    NWC 빈 View 처리와 추출 설정 파일

    여러 View를 연속 추출할 때 객체가 없는 View와 호환 경고 때문에 작업 전체가 멈추지 않도록 처리 범위를 넓히고, 반복해서 사용하는 NWC 옵션을 JSON 파일로 저장·불러올 수 있게 한 버전입니다.

    • NWC Export는 Revit 2019, 2021, 2023, 2025, 2027에서 객체가 없는 View를 건너뜀으로 기록한 뒤 다음 View와 RVT를 계속 처리합니다.
    • 객체 없는 View 표시 TXT 생성을 켜면 NWC 대신 같은 기본 이름의 _객체없음.txt를 남깁니다. 끄면 결과에만 원인을 기록하며, 일반 Export 실패나 NWC 파일 미생성은 계속 오류로 구분합니다.
    • 호환되지 않는 프린터 또는 Print Setup 경고는 정확한 경고 문구가 확인된 경우에만 자동으로 닫고 자동 처리 경고에 남깁니다. 다른 Revit 대화상자를 임의로 닫지 않습니다.
    • 설정 파일 저장 / 불러오기로 파일 이름, 좌표, 파라미터, Faceting Factor와 출력 옵션을 JSON 파일에 보관할 수 있습니다. 불러온 값은 다음 실행에 자동 기억되고 열려 있는 다른 Revit의 KKY Tool에도 공유됩니다.
    • 설정 파일에는 RVT, 3D View, Revit Link, NWC 저장 폴더, 진행률과 결과가 포함되지 않으므로 현재 작업 대상은 바뀌지 않습니다.
    • NWC 저장 폴더의 찾아보기 창은 KKY Tool 창을 기준으로 앞에 열리도록 수정해, 결과나 설정창 뒤에 가려져 무응답처럼 보이던 문제를 줄였습니다.
  4. 정식 버전3.0.132026.08.27

    ACC 작업 중 문서 UI 안정화와 센트럴 실파일 재검증

    ACC/Autodesk Docs 동기화나 문서 전환과 겹칠 때 문서 탭 색상과 Navigator가 Revit 화면을 건드리는 시점을 조정하고, 센트럴·웍셋 작업은 경로 문자열이 아니라 실제 연결 파일을 다시 확인하도록 보완한 버전입니다.

    • 문서 탭 색상과 Document Navigator는 문서 열기·닫기, Reload, Synchronize with Central이 진행되는 동안 바로 화면을 탐색하지 않고 Revit이 안정된 Idling 상태로 돌아온 뒤 갱신합니다.
    • Navigator에서 문서를 여는 요청은 Revit ExternalEvent로 순서대로 처리합니다. 작업 중 상태가 반복해서 불안정하면 해당 Revit 세션의 탭 색상 처리를 중지해 ACC 작업과의 충돌을 피합니다.
    • 센트럴 / 웍셋 작업은 매핑 드라이브와 UNC처럼 같은 파일을 서로 다른 경로로 표시하는 경우에도 Windows 파일 ID로 실제 파일이 같은지 확인합니다. 문자열만 달라졌다는 이유로 정상 작업을 막지 않습니다.
    • 사전 검증 뒤 원본 RVT의 센트럴 연결이 다른 실제 파일로 바뀌었거나 파일 ID를 확인할 수 없으면 소유권 변경, 임시 로컬 생성, 저장을 시작하기 전에 작업을 차단합니다.
    • Revit 2019, 2021, 2023, 2025, 2027 지원을 유지합니다.
  5. 정식 버전3.0.122026.08.26

    ACC TEST 작업 추가와 센트럴·재질 검토 흐름 보완

    ACC/Autodesk Docs의 새 Cloud Workshared 모델 생성과 LAN 센트럴 snapshot 백업을 전용 TEST 흐름으로 추가하고, 센트럴/웍셋 Excel 입력 안정화와 UTILITY 재질 검토의 파일명 분야 판정을 보완한 버전입니다.

    • ACC 클라우드 모델 생성 (TEST)은 파일 RVT를 새 ACC/Autodesk Docs Cloud Workshared 모델로 만드는 별도 작업창입니다. Revit 2023, 2025, 2027에서만 실행하며, AccountGuid·ProjectGuid·FolderId/URN·Region과 모델명을 행별로 지정합니다. 기존 원격 모델 덮어쓰기는 하지 않고, 생성 여부가 불확정인 target은 수동 확인 전 재실행을 차단합니다.
    • ACC 백업 (TEST)은 LAN file-based central의 성공 SWC를 queue에 기록한 뒤 닫힌 staging snapshot을 만들고, 별도 ACC ordinary RVT Item의 새 Version으로 보관합니다. 기본값은 dry-run이며 RCW/C4R Item, live central 직접 복사·업로드, 운영 folder write를 막는 안전 조건을 둡니다.
    • 센트럴 / 웍셋 작업은 여러 창 사이의 설정 동기화가 입력·한글 조합·caret·스크롤을 끊지 않게 정리했고, RVT 등록만 끝난 상태에서도 Excel 일괄 설정 양식을 먼저 내보낼 수 있게 보완했습니다. 기존 worksetmanager 항목은 통합 기능과 권한 탭으로 정리했습니다.
    • UTILITY 재질 오류 검토는 파일명 구간의 분야 판정을 보완했습니다. 대문자 R로 끝나는 두 번째 구간, H/P/E/I/GTG/GCH 코드와 ETL 우선 규칙을 기준으로 EX·HVAC·PIPE·ELEC·INST·TOXIC GAS·CHEMICAL·TELECOM 분류를 더 안정적으로 적용합니다.
    • KKY Tool 전체는 Revit 2019, 2021, 2023, 2025, 2027 지원을 유지합니다. ACC 테스트 기능은 화면의 제한과 전용 매뉴얼을 먼저 확인한 뒤 사용해야 합니다.
  6. 정식 버전3.0.112026.08.20

    기준 RVT 하나로 여러 새 센트럴을 만드는 Excel 작업 행 지원

    센트럴/웍셋 Excel 양식에서 하나의 기준 RVT를 여러 작업 행으로 복사해 각각 다른 새 센트럴 파일을 만들 수 있도록 정리하고, 행별 상태와 출력 경로 충돌 검증을 보강한 버전입니다.

    • 센트럴 / 웍셋 작업 Excel에서 같은 SourceRvtPath를 여러 행에 사용할 수 있습니다. 각 행은 RowId와 OutputCentralPath를 기준으로 독립된 새 센트럴 생성 작업으로 보존됩니다.
    • 기준 행을 복사해도 첫 번째 고유 RowId는 유지하고, 복사한 행의 빈 값 또는 중복 RowId는 가져올 때 자동으로 새 ID를 부여합니다.
    • 같은 실제 파일 또는 같은 대상 경로를 가리키는 OutputCentralPath 중복은 Excel 가져오기에서 두 행 번호와 함께 차단합니다. 원본 RVT나 연결 센트럴 자체를 출력 경로로 쓰는 경우도 실행 전과 저장 직전에 다시 막습니다.
    • 화면에서 RVT를 직접 등록할 때의 기존 중복 파일 등록 규칙은 그대로 유지합니다. 한 기준 RVT를 여러 출력 센트럴로 나누는 작업은 Excel 양식에서만 지원합니다.
    • Revit 2019, 2021, 2023, 2025, 2027 지원을 유지합니다.
  7. 정식 버전3.0.102026.08.20

    센트럴·웍셋 작업, 3D 뷰 템플릿 및 Shared Levels and Grids Workset 권한과 Action 기반 링크 경로 적용

    새 센트럴을 안전하게 만드는 흐름을 센트럴·로컬·일반 RVT까지 확장하고, 지정 3D 뷰 템플릿과 exact-name Shared Levels and Grids UserWorkset의 Owner/Editable 유지, 링크 경로 Excel의 Action 기반 적용을 보강한 버전입니다.

    • 센트럴 / 웍셋 작업에서 센트럴, 로컬, 일반 RVT를 같은 목록으로 읽고 파일별 새 센트럴 경로·기존 웍셋·추가 웍셋을 확인할 수 있습니다. 센트럴과 로컬은 웍셋을 보존해 Detach한 뒤 전체 웍셋을 닫아 새 경로에 만들고, 일반 RVT는 Worksharing을 켠 뒤 새 센트럴로 저장합니다.
    • 기록된 연결 센트럴을 찾지 못하는 로컬/복사본도 센트럴 파일 만들기에서는 경고 후 새 센트럴 생성 대상으로 사용할 수 있습니다. 반대로 웍셋만 확인·추가는 실제 연결 센트럴이 있는 파일에서만 실행합니다.
    • 추가할 사용자 웍셋은 개수 제한 없이 입력하거나 Excel의 AddWorkset1 이후 열로 배치 지정할 수 있습니다. 같은 이름은 자동으로 건너뛰며, 출력 경로는 원본과 다른 절대 .rvt 경로만 허용합니다.
    • 새 센트럴은 기본으로 Revit 소유권을 모두 반납합니다. 필요할 때 선택한 비템플릿 3D View의 ViewWorkset과 이름이 정확히 일치하는 지정 3D 뷰 템플릿의 primary ViewWorkset을 현재 사용자 소유·편집 가능 상태(Owner=current, Editable=Yes)로 유지합니다. Revit이 요구하는 필수 pair/internal closure를 검증하며, 해당 closure에 비대상 View 또는 템플릿이 포함되면 안전을 위해 작업을 차단합니다.
    • 별도 Level/Grid 옵션은 등록 RVT 본문의 모든 Level/Grid를 Pin 고정하고 이름이 대소문자까지 정확히 Shared Levels and Grids인 UserWorkset 하나만 현재 사용자 소유·편집 가능 상태(Owner=current, Editable=Yes)로 유지합니다. Workset 전체가 잠기므로 같은 Workset에 배치된 비-Level/Grid 요소도 다른 사용자가 수정하지 못할 수 있으며, 다른 UserWorkset과 개별 요소 대여는 최종 반납합니다. 링크 모델의 Level/Grid는 제외됩니다.
    • Revit 링크 경로 추출/재지정 Excel v2는 유지, Reload From, 신규 링크, 삭제 Action을 명시한 행만 처리합니다. 대상 경로를 비워도 삭제되지 않으며, 삭제는 반드시 Action을 삭제로 지정해야 합니다.
    • 링크 추출·적용 결과는 결과 / 대상 / 작업 / 원인 · 조치 4열로 정리해 확인합니다. 적용은 호스트·행별로 저장과 재확인을 거치며, 이미 확인된 성공 행은 이후 다른 행이 실패해도 되돌리지 않습니다.
    • Schedule Import/Export 설정은 입력 중인 값, 스크롤 위치, 포커스와 한글 조합 상태를 유지하도록 보완했습니다. Revit 2019, 2021, 2023, 2025, 2027 지원을 유지합니다.
  8. 정식 버전3.0.92026.08.12

    링크 경로 상태 확인과 설정 입력 안정화

    여러 RVT의 Revit 링크 경로를 추출·적용할 때 현재 링크 상태와 경로 정보를 먼저 확인할 수 있도록 보강하고, 설정값을 입력하는 동안 화면이 다시 그려지는 문제를 줄인 버전입니다.

    • Revit 링크 경로 추출/재지정에서 현재 경로, 링크 방식, Loaded/Unloaded/NotFound 등 링크 파일 상태를 함께 확인할 수 있습니다.
