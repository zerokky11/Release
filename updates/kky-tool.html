  1. 현재 배포3.0.102026.08.19

    센트럴·웍셋 작업과 Action 기반 링크 경로 적용

    새 센트럴을 안전하게 만드는 흐름을 센트럴·로컬·일반 RVT까지 확장하고, 링크 경로 Excel은 작업 종류를 명시한 행만 적용하도록 정리한 버전입니다.

    • 센트럴 / 웍셋 작업에서 센트럴, 로컬, 일반 RVT를 같은 목록으로 읽고 파일별 새 센트럴 경로·기존 웍셋·추가 웍셋을 확인할 수 있습니다. 센트럴과 로컬은 웍셋을 보존해 Detach한 뒤 전체 웍셋을 닫아 새 경로에 만들고, 일반 RVT는 Worksharing을 켠 뒤 새 센트럴로 저장합니다.
    • 기록된 연결 센트럴을 찾지 못하는 로컬/복사본도 센트럴 파일 만들기에서는 경고 후 새 센트럴 생성 대상으로 사용할 수 있습니다. 반대로 웍셋만 확인·추가는 실제 연결 센트럴이 있는 파일에서만 실행합니다.
    • 추가할 사용자 웍셋은 개수 제한 없이 입력하거나 Excel의 AddWorkset1 이후 열로 배치 지정할 수 있습니다. 같은 이름은 자동으로 건너뛰며, 출력 경로는 원본과 다른 절대 .rvt 경로만 허용합니다.
    • 새 센트럴은 기본으로 Revit 소유권을 모두 반납합니다. 필요할 때만 선택한 비템플릿 3D View의 ViewWorkset을 현재 사용자 소유로 다시 확보할 수 있습니다.
    • Revit 링크 경로 추출/재지정 Excel v2는 유지, Reload From, 신규 링크, 삭제 Action을 명시한 행만 처리합니다. 대상 경로를 비워도 삭제되지 않으며, 삭제는 반드시 Action을 삭제로 지정해야 합니다.
    • 링크 추출·적용 결과는 결과 / 대상 / 작업 / 원인 · 조치 4열로 정리해 확인합니다. 적용은 호스트·행별로 저장과 재확인을 거치며, 이미 확인된 성공 행은 이후 다른 행이 실패해도 되돌리지 않습니다.
    • Schedule Import/Export 설정은 입력 중인 값, 스크롤 위치, 포커스와 한글 조합 상태를 유지하도록 보완했습니다. Revit 2019, 2021, 2023, 2025, 2027 지원을 유지합니다.
  2. 정식 버전3.0.92026.08.12

    링크 경로 상태 확인과 설정 입력 안정화

    여러 RVT의 Revit 링크 경로를 추출·적용할 때 현재 링크 상태와 경로 정보를 먼저 확인할 수 있도록 보강하고, 설정값을 입력하는 동안 화면이 다시 그려지는 문제를 줄인 버전입니다.

    • Revit 링크 경로 추출/재지정에서 현재 경로, 링크 방식, Loaded/Unloaded/NotFound 등 링크 파일 상태를 함께 확인할 수 있습니다.
    • 추출 결과에서 링크 오류, 미로드·주의, 추출 경고, 대상 지정, 삭제 후보를 나누어 표시해 경로를 바꾸기 전에 상태를 검토하기 쉬워졌습니다.
    • 이후 3.0.10에서 Excel 적용 규칙을 Action 기반으로 다시 정리했습니다. 현재는 TargetLinkPath가 비어 있다는 이유만으로 삭제하지 않으며, Action=삭제 행만 삭제 대상으로 처리합니다.
    • NWC Export와 여러 기능 설정 화면은 입력·선택·한글 조합 중 공유 설정 동기화가 들어와도 즉시 화면을 다시 그리지 않고, 입력을 마친 뒤 반영하도록 보완했습니다.
    • Revit 2019, 2021, 2023, 2025, 2027 지원을 유지합니다.

    • 센트럴 파일 생성과 웍셋 확인·추가를 여러 RVT 전용 독립 작업창으로 구성했습니다.
    • 파일명 검색과 상태 필터로 대상 RVT를 빠르게 좁힐 수 있고, 각 행을 APPLY 또는 SKIP으로 구분해 실행 범위를 명확히 표시합니다.
    • 선택한 파일의 기존 웍셋을 상세히 확인하고, 공통으로 추가할 웍셋 이름을 입력해 대상별 적용 내용을 미리 검토할 수 있습니다.

    • Nozzle 허용 미연결 규칙을 추가했습니다. 켜면 Family 이름에 Nozzle이 있는 객체는 기본 1개 미연결을 허용하며, Box Nozzle은 이름의 숫자만큼을 허용합니다. 단, 양 끝단이 끊긴 경우는 계속 오류로 남깁니다.

    • 여러 기능 설정 화면은 상세 설정을 열거나 값을 적용한 뒤에도 현재 보고 있던 스크롤 위치를 유지하도록 정리했습니다.
    • 여러 RVT 링크 경로 검토·적용은 링크 정보 읽기, 경로 적용, 진행 상태와 열린 문서 정리 흐름을 보완했습니다.

    Reducer 기준 검토, 새 센트럴 생성과 링크 좌표 검토표 보강

    반복 확인이 필요했던 배관 Reducer 표기, 센트럴 파일 생성·웍셋 추가, 여러 RVT 링크 좌표 검토 흐름을 각각 독립 기능과 검토표 기준으로 정리한 버전입니다.

    • Reducer Point 정합성 검토를 추가했습니다. Pipe Fittings 중 패밀리명에 Reducer가 포함된 객체만 대상으로, 타입명과 Point 파라미터의 ECC/CON 표기가 맞지 않는 행을 오류 Excel로 저장합니다.
    • 센트럴 파일 생성 및 웍셋 추가를 추가했습니다. 활성 문서 또는 여러 RVT를 원본과 분리된 새 센트럴로 만들고, 입력한 사용자 웍셋은 없는 이름만 추가합니다. 원본 RVT에는 저장하지 않습니다.
    • Link 파일 Shared Coordination은 활성 문서·여러 RVT의 링크 상태를 Excel 검토표로 내보낸 뒤, 다시 검증된 APPLY 행만 반영하도록 보강했습니다. 최초 링크 배치 방식은 Revit API가 제공하지 않아 확인 불가로 표시하며, 현재 배치 추정·인스턴스 Shared Site·링크 Active Site를 구분해 확인합니다.
    • Grid / Level 기준 정합성에서 방향 차이가 20도보다 작은 거의 평행한 Grid 조합의 원거리 허위 교차점을 제외하고, 활성 문서 결과가 중복 표기될 수 있던 흐름과 결과 Excel의 대상 파일명 표기를 정리했습니다.
    • 미연결 검토의 경사도 범위에 최소 각도 설정을 더했습니다. 기본값은 0.01도 초과~15도 이하이며, 작은 경사도는 판정값이 보이도록 표시 정밀도를 높였습니다.
    • 속성 기준값 검토는 기준값과 CUSTOM# 조합을 대소문자까지 구분해 비교합니다. 새 기능과 변경 기능의 상세 가이드 버튼도 홈페이지 매뉴얼로 연결했습니다.

    Grid/Level 정합성, Shared Coordination과 여러 RVT 저장 흐름 보강

    Grid/Level 정합성과 Shared Coordination 검토를 추가하고, 여러 RVT 결과 저장과 Excel 출력 안정성, 업데이트 표시를 함께 보강한 정식 버전입니다.

    • Grid / Level 기준 정합성 검토를 추가했습니다. 기준 RVT 또는 Level 기준 Excel과 대상 문서의 직선 Grid 위치·방향·교차점, Level Project Elevation을 Internal Origin 기준으로 비교합니다.

    • 여러 RVT 실행 전에 실행 후 직접 저장, 기능별 통합 Excel 순차 저장, RVT별 Excel 즉시 저장 중 하나를 선택하도록 했습니다. 자동 저장은 폴더 선택을 취소하면 검토도 시작하지 않습니다.
    • 대용량 Excel 저장에서 시스템 글꼴을 찾지 못해 열 너비 자동 맞춤이 실패하는 환경을 보호하고, 자동 맞춤을 끄면 빠른 저장을 유지하도록 보완했습니다.
    • 기준점/북각 추출의 Internal Origin 공유좌표가 고정 0이 아니라 활성 Project Location 변환값으로 기록되도록 수정했습니다.
    • 업데이트 화면의 최신 버전 숫자가 실제 서버 최신 버전과 다르게 보일 수 있던 표시 경로를 정리했습니다.
  7. 정식 버전3.0.42026.08.04

    Schedule Export 대용량 저장과 실행 순서 개선

    실행 전에 Excel 구성과 저장 위치를 확정하고, 여러 RVT 결과를 문서 단위로 기록·해제해 파일 수가 많아져도 추출 데이터가 메모리에 계속 쌓이지 않도록 바꿨습니다.

    • 통합 파일 또는 RVT별 파일, 시트 구성, 빠른·일반 추출, 한글·영문과 저장 위치를 실제 RVT 추출 전에 먼저 선택합니다. 저장 선택을 취소하면 대상 RVT를 열지 않습니다.
    • RVT별 저장은 문서 하나를 열어 추출·저장하고 닫은 뒤 다음 파일로 넘어갑니다. 문서를 닫지 못하면 메모리 누적을 막기 위해 남은 작업을 중단하고 오류를 남깁니다.
    • 통합 Excel은 문서별 결과를 압축 임시 스트림에 순차 기록한 뒤 마지막에 완성 파일로 교체합니다. 취소나 실패 시 미완성 파일과 임시 데이터를 정리합니다.
    • 문서별 처리 행·링크 행·오류와 전체 합계를 결과 및 Export Log에 유지하며 Revit 2019, 2021, 2023, 2025, 2027 지원을 이어갑니다.
  8. 정식 버전3.0.32026.08.03

    Schedule Export 파라미터 매핑과 대상 RVT 처리 안정화

    전체 객체 + 스케줄 필드 추출에서 기준 Schedule의 필드를 대상 RVT 파라미터에 연결하는 규칙을 명확히 하고, 임시 Schedule 적용 과정에서 생길 수 있는 경고와 문서 변경을 안전하게 처리했습니다.

    • Revit 기본 파라미터는 내부 ID, Shared Parameter는 GUID, 일반 Project Parameter는 대소문자까지 같은 유일한 이름을 기준으로 연결합니다.
    • GUID 불일치, 이름 중복, 계산 필드, 실제 빈 값은 임의의 다른 파라미터로 대체하지 않고 빈 셀로 유지하며, 원인별 건수와 Element ID 예시를 Export Log에 남깁니다.
    • 다른 문서의 Schedule을 대상 RVT에 임시 적용할 때 타입 중복과 패밀리 이름 관련 알림을 처리하고, 데이터 추출 뒤 트랜잭션 전체를 되돌려 대상 파일에 복사본을 남기지 않습니다.
    • 길이·면적·체적·각도 등 수치 값은 기준 Schedule 문서의 프로젝트 단위를 따르며 Revit 2019, 2021, 2023, 2025, 2027 지원을 유지합니다.
