    빠른 엑셀 저장 확대와 실행 불가 환경 대응

    빠른 Excel 저장 지원 범위를 공통·특수 검토 결과로 확대했습니다. 외부 작성기를 시작할 수 없는 경우에는 기존 저장 방식으로 전환하며, 여러 파라미터 연속성 검토의 반복 조회를 줄였습니다. 기존 결과 값·서식과 추가 파라미터·필터·매핑·다회차 설정은 유지합니다.

    • 빠른 엑셀 저장 확대: 공통 검토와 특수 검토 결과에서도 외부 작성 방식을 사용합니다. 기존 저장 옵션과 결과의 값·자료형·행 순서·서식을 유지하며 여러 RVT 통합 저장도 지원합니다.
    • 작성기 미시작 시 자동 전환: 외부 작성기가 시작되지 않아 요청도 전달되지 않은 경우에만 기존 내부 작성기로 저장합니다. 정상적인 빠른 저장은 그대로 사용합니다.
    • 중복 저장 방지: 이미 시작한 작성기의 통신·저장 오류는 기존 방식으로 다시 실행하지 않습니다. 실행 차단과 저장 중 오류를 구분해 처리합니다.
    • 여러 파라미터 연속성 검토: 반복적인 이름·타입 조회를 줄였습니다. 단일 파라미터 검토 경로, 연결 판정과 기존 결과 기준은 유지합니다.
    • 설정과 결과 유지: 추가 파라미터·매핑·Match 및 빈값 제외·다회차 답변과 수량·기존 출력 형식을 유지합니다. 앞선 기둥넘버 여러 RVT 검토와 파일별 설정 보완도 포함합니다.
    • 통합 설치: 기존 Link Manager와 NWC Exporter plus 1.0.1 Fix8 전체 구성을 함께 설치합니다. 설치 전 Revit과 NWC Exporter를 종료하세요.
    • 확인 범위: 실제 Revit 시험 모델의 결과 비교와 작성기 실행 차단 조건을 확인했습니다. 새 설치본을 설치한 원격 PC와 회사 보안 프로그램 환경의 동작은 별도 확인이 필요합니다.
  2. 정식 버전3.1.202026.10.28

    대형 모델 엑셀 처리 개선과 기둥넘버 검토 보완

    빠른 연속성·속성 누락·모수 검토의 엑셀 작성 작업을 별도 프로세스로 옮겨 대형 결과의 저장 시간을 줄였습니다. 기둥넘버 여러 RVT 검토와 파일별 제외 설정, 결과 집계·출력 안내를 보완하고 NWC Exporter plus 1.0.1 Fix8을 포함했습니다.

    • 엑셀 처리 분리: 빠른 연속성·속성 누락·모수 검토의 표 준비와 엑셀 작성을 별도 작업자로 처리합니다. 여러 RVT 통합 저장에도 적용하며 추가 파라미터, 매핑, 빈값·Match 제외, 문서별 시트와 다회차 답변 형식은 유지합니다.
    • 여러 RVT 결과 안내: 한 기능의 집계 오류가 다른 결과를 지우지 않도록 보완했습니다. 집계 불가와 파일 열기 실패는 이유를 표시하며, 불완전한 커넥터 결과를 오류 없는 검토 파일로 저장하지 않습니다.
    • 개별 등록 저장 옵션: 활성 문서 개별 등록 검토의 표시를 실제 출력 단위에 맞추고, 저장 창 이후의 늦은 응답이 다른 실행의 설정을 덮어쓰지 않도록 보완했습니다.
    • 기둥넘버 여러 RVT 검토: 호스트별 구조 RVT를 등록하고 원점·공유 좌표·중심·기준점 배치 방식으로 순차 검토할 수 있습니다. 통합 결과에 파일명을 표시하고 실패·미실행 파일은 별도 처리 기록으로 남깁니다.
    • 기둥넘버 설정·결과: 구조 패밀리 제외 목록을 조회해 파일별로 선택할 수 있습니다. 구조 입력값 제목에는 검토한 파라미터명을 표시하며, 엑셀 그룹 색·테두리와 객체 ID 표시를 정리했습니다.
    • 검토 대상과 반복 읽기: 파라미터·UTILITY 재질 검토의 반복 조회를 줄였습니다. 레벨 영역별 검토에서는 대상 파라미터가 인스턴스와 타입 모두에 없는 객체를 제외하며, 존재하지만 빈 값인 객체는 계속 검토합니다.
    • NWC 연결 보완: NWC Exporter plus 1.0.1 Fix8을 함께 설치합니다. 활성 문서·뷰 조회와 새로고침·추출·취소·결과 전달, 기존 창 연결을 중간 파일 없이 처리하도록 변경했습니다. Revit과 Exporter를 종료한 뒤 통합 설치파일로 업데이트하세요.
    • 확인 범위: Excel 개선은 실제 Revit 2021의 대형 시험 모델에서 결과 파일을 비교했습니다. 회사 모델·네트워크 저장소의 속도를 보장하는 수치는 아니며, 다른 Revit 버전과 원격 PC의 실제 설치·실행은 별도 확인이 필요합니다.
  3. 정식 버전3.1.192026.10.27

    UTILITY 판정과 공통 필터·답변 저장 보완

    UTILITY 검토의 CLASS별 기준 적용과 공통 필터 저장을 보완하고, 다회차 결과 정리의 답변 열 선택·문구 저장을 수정했습니다.

    • UTILITY 검토는 기존 카테고리·공통 필터 수집 범위를 유지하면서, 이미 수집된 객체의 실제 CLASS에 해당하는 프로젝트 기준으로 Utility와 재질을 비교합니다. 파일명에서 선택한 수집 분야와 CLASS가 다르다는 이유만으로 객체를 제외하지 않습니다.
    • 동을 전체로 선택하면 특정 동으로 강제하지 않습니다. 특정 동을 선택한 경우에는 객체의 동과 정확히 비교하며, CLASS·동·Utility·재질의 필수값 누락과 객체별 기준 부재를 구분해 표시합니다.
    • 기준 Excel의 선택 열 Comments·Comment·비고를 읽어 해당 기준의 안내 내용을 결과에 반영합니다. 해당 열이 없는 기존 양식도 사용할 수 있습니다.
    • 공통 객체 필터의 AND·OR 조합, 값 없음 조건과 적용 버튼의 저장 연결을 수정했습니다. 다시 열거나 실행할 때 적용한 조건을 유지하고, 늦게 도착한 설정 응답이 현재 조건을 덮어쓰지 않도록 보완했습니다.
    • 공유 설정 저장에서 UTILITY 설정 키가 거부되어 같은 요청의 공통 설정까지 저장되지 않던 문제를 수정했습니다. 설정 저장 실패 안내도 보완했습니다.
    • 제외한 객체가 커넥터의 연결 상대를 통해 검토에 다시 들어오는 경로를 보완했습니다. 기존 포함·제외 조건과 물리 연결 판정은 유지합니다.
    • 다회차 결과 정리에서 자동·수동으로 선택한 답변 열, 기본 결과 열과 새 답변 열의 문구 계승을 보완했습니다. 문구 저장과 오류 수량 판정은 분리하며, 반영할 수 없는 답변은 확인 필요로 남깁니다.
    • 여러 답변 열을 저장할 때 자동으로 붙던 열 이름을 제거하고 선택한 답변 내용만 줄바꿈으로 저장합니다. 사용자가 직접 입력한 대괄호·문구와 기존 치환·수량 기준은 유지합니다.
    • NWC Exporter plus 1.0.1 Fix7 전체 구성을 계속 함께 설치합니다. 이번 KKY 버전업에서 NWC 버전이나 Family Browser 배포 상태는 변경하지 않습니다.
    • 파일명 자동 매핑의 단일 후보 처리, 점이 포함된 문서 제목과 기준 양식의 우선순위 헤더 해석은 별도 점검 사항이며 이번 버전에서 해결 완료로 표시하지 않습니다.
    • 이번 배포 작업의 확인 범위는 다섯 Revit 버전의 빌드·서명·포함 파일과 공개 다운로드 확인입니다. 실제 사용자 모델·원격 PC 설치와 Revit 실행은 별도 확인이 필요합니다.

    • 커넥터 연속성의 등록 항목에서 빠진 필터·매핑 설정을 상위 설정과 일관되게 적용하고, 명시한 끔·빈 선택은 보존합니다. 추가 출력 파라미터 조회도 최적화했습니다.
    • Link객체 확인 도구에서 Revit 2021을 지원하고, 선택한 링크 객체들을 링크 배치와 회전을 반영해 현재 뷰에서 함께 확대하도록 보완했습니다.

    공통 집계와 패밀리 연동·GUID 검토 보완

    공통 정상 건수 집계에 더해 패밀리 공유파라미터 연동 검토의 정상 통계와 GUID 검토의 참고 행 분류를 보완했습니다.

    • 패밀리 공유파라미터 연동 검토에서 정상 항목의 상세 행을 오류 목록에 남기지 않더라도 실제 정상 건수가 집계되도록 보완했습니다. 정상·오류가 함께 있는 경우에도 각각의 수를 유지합니다.
    • 파라미터 GUID 검토 및 정리에서 BUILTIN과 FAMILY_PARAM 참고 행을 오류 건수에서 제외했습니다. 실제 GUID 불일치·공유파라미터 파일에 없는 GUID·읽기 실패 등의 오류 판정은 유지합니다.
    • 여러 기능을 함께 실행한 결과의 정상 건수는 각 기능이 실제로 계산한 값을 합산합니다. 서로 다른 기능의 오류 수를 한 기능의 전체 수에서 빼서 정상을 추정하지 않습니다.
    • 미연결 검토는 대상 객체·오류 객체·정상 객체의 같은 단위로 표시합니다. 보조 검사를 켜서 전체 정상 수를 별도로 계산하지 않는 경우에는 추정값 대신 —를 표시합니다.
    • 실제 정상 0건과 정상 수 미계측을 구분합니다. 미계측은 —로 표시하고, 중단·실패·정보 행을 정상 결과로 취급하지 않습니다.
    • 알려진 사항: 일부 시험에서 검토 완료 후 모델을 닫는 중 Revit 충돌이 발생해 별도로 원인을 확인하고 있습니다. 이번 공통 집계 수정의 검증과 모델 닫기 안정성은 구분합니다.
    • 파라미터 연속성 검토에서 정상 비교 건수를 오류 행과 분리해 집계합니다. 검토가 끝나지 않은 파일을 완료로 표시하지 않습니다.
    • 이미 열린 동일 로컬 RVT를 여러 RVT 검토에서 다시 열지 않고 재사용합니다. 실행 중 직접 연 문서만 저장하거나 닫으며, 열린 문서를 변경하는 일부 작업은 활성 문서 방식으로 안내합니다.
