FAMILY BROWSER RELEASE NOTES

Family Browser 업데이트 내역

실제로 공개된 버전과 수정 배포를 준비하는 버전을 분리해 기록합니다.

공개 피드 기준1.02026.07.20
전체 KKY Tool Family Browser
안내

Family Browser 1.0.1은 수정본을 준비하고 있어 현재 설치 파일과 업데이트 피드에서 내린 상태입니다. 재배포가 끝날 때까지 홈페이지 다운로드 버튼도 비활성으로 유지합니다.

Family Browser 1.x

표준 라이브러리 운영과 현재 모델 검사를 위한 버전 기록입니다.

매뉴얼 보기
  1. 수정 배포 준비 중1.0.12026.07.21

    상세 비교와 변경 추적 보완

    System Type을 더 세밀하게 비교하고 프로젝트 변경 이력을 안정적으로 남기기 위한 수정본입니다. 현재는 재검토 중이므로 설치 파일을 제공하지 않습니다.

    • Railing, Stair 같은 System Type의 내부 구성 요소까지 비교하는 옵션을 추가했습니다.
    • 프로젝트 요소의 생성·수정·삭제 추적과 로컬·공용 저장 흐름을 보완했습니다.
    • 홈 대시보드와 프로젝트 이름 카탈로그의 상태 표시를 정리했습니다.
    • 수정본 검증이 끝난 뒤 같은 1.0.1 버전으로 다시 배포할 예정입니다.
  2. 정식 배포 기준1.02026.07.20

    표준 라이브러리 운영 첫 정식 버전

    관리 폴더와 표준 RVT를 연결해 승인된 패밀리·시스템 타입을 찾고, 현재 모델의 표준 준수 상태를 확인하는 첫 공개 버전입니다.

    • 관리 폴더, 표준 RVT, 정밀 스캔, 표준 목록 Excel 연결 순서로 초기 환경을 구성합니다.
    • 패밀리와 시스템 타입을 검색하고 표준 RVT에서 현재 프로젝트로 불러옵니다.
    • 미등록 패밀리와 표준 원본 변경 여부를 검사하고 검토용 Excel을 내보냅니다.
    • 프로젝트 이름 카탈로그, 추가 요청, 권한 정책과 파일 잠금 상태를 관리합니다.
    • Revit 2019, 2021, 2023, 2025, 2027을 지원합니다.
