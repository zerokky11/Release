기능 요청

반복되는 불편을 기능 요청으로 남기기

검토 자동화, 결과 정리, UI 흐름 개선처럼 실제 프로젝트에서 반복되는 작업을 등록합니다. 저장 방식은 기존 운영 요청 API를 그대로 사용합니다.

요청 내용

프로젝트 원본 데이터, 개인 연락처, 보안 정보는 제외하고 상황과 기대 결과 중심으로 작성하세요.

요청 등록 후 최근 요청 목록에서 바로 확인할 수 있습니다.

최근 요청

팀에서 등록한 최근 요청을 확인합니다.

등록된 요청을 불러오는 중입니다.

작성 기준

  • 작업을 누가, 언제, 얼마나 자주 반복하는지 적습니다.
  • 현재 수작업 단계와 원하는 자동화 결과를 구분합니다.
  • 검토 기준, 엑셀 양식, 결과 파일명처럼 판단에 필요한 조건을 함께 적습니다.
  • 프로젝트 보안 정보나 원본 데이터 경로는 제외합니다.

처리 흐름

  1. 요청 등록

    입력값을 기존 요청 API에 저장합니다.

  2. 검토

    반복성, 위험도, 구현 범위를 보고 우선순위를 정합니다.

  3. 반영

    기능 카탈로그와 메뉴얼에 반영할 항목을 정리합니다.
